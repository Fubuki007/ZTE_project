# 粗测角修复：正式全量复测结果（2026-11-17）

本轮重放上一轮的 300 个几何样本和三档 RCS，共 900 个工况。每个工况使用同一份接收波束合并数据、同一距离–多普勒峰、同一噪声和精估计流程，只改变粗测角处理。4 种方法共 3,600 行指标，8 个服务器进程全部完成，独立 Python 复核通过。

## 结论

**真正有效的是全阵列匹配测角，不是单独修改干扰消除的相位正负号。**原方法的相邻阵元相位差在弱空间信号下不稳定；全阵列方法利用 64 路空间快拍的整体相位结构，明显降低了低 RCS 的角度离群值。

RCS=10 时，全阵列匹配将 NoRIS 粗测后的定位 RMSE 从 **125.59 m 降到 36.90 m**，严格失败率从 **86.33% 降到 77.67%**。配对 bootstrap 4,000 次的主要比较为：RMSE 减少 **70.62%**，95% 区间 **[61.24%, 81.05%]**；失败率减少 **8.67 个百分点**，95% 区间 **[4.33, 13.00] 个百分点**。这说明测角修复对 RCS=10 有稳定改善，但绝对误差仍远大于 5 m，不能说已经可用。

单独改干扰消除符号反而没有改善：RCS=10 RMSE 为 128.35 m，RCS=100 甚至变成 19.34 m。取消干扰消除比原方法稍好，但仍远不如全阵列匹配。因此，“代码里存在正负号问题”不是完整解释；问题的主体是相邻阵元相位估计和随后投影消除在低空间 SNR 下不稳。

## 为什么会这样

原流程先用距离–多普勒峰分离目标，再从空间快拍取 SVD 主方向，最后用相邻阵元相位差估两个方向余弦，并进行两轮空间投影。低 RCS 时相邻阵元的乘积容易被噪声和多目标污染；投影使用的方向一旦偏了，还会把目标本身的能量削掉。

全阵列方法对已有快拍做二维空间匹配：用零填充空间 FFT 找初值，再在物理方向余弦圆盘内优化整体匹配功率。它没有增加天线、子载波、符号或导频，也没有使用真实角度；只是更充分地使用已有 64 路空间数据。零填充只提高搜索网格密度，不增加物理孔径。

## 能否说明 RIS 已经可用

还不能。此次对照关闭 RIS，只验证测角环节，所以结果证明的是“角度估计可以明显修复”，不是 RIS 增益。RCS=10 即使测角修复后仍有 77.67% 严格失败，36.90 m RMSE 也远未达到 5 m 目标。

下一步应把全阵列匹配测角接回 RIS 对照链路，再用新的独立几何和随机种子比较 NoRIS、固定 RIS、无人机位置优化 + RIS。只有在相同资源下 RIS 相对 NoRIS 在独立样本上持续降低绝对定位误差和失败率，才能说 RIS 真正适用于当前场景。
