## 这轮回答什么

保留物理信号里的四条路径，检查估计时是否应当使用全部路径、筛掉弱路径，
或者降低弱路径的拟合权重。先判断是否存在可重复的收益，再决定是否值得做
新的联合优化方法。AIC/BIC 和 ridge 都是现成方法，这轮不能据此声称算法创新。

沿用用户指定的 Stage-3 代码，原函数不变。正式规模为 300 个配对 Monte Carlo
样本 × 13 个 SNR，共 3900 组；每组比较能量设计和 PEB 设计两种 RIS 条件，
同时保留能量设计与 PEB 设计两个无 RIS 对照。阵列、子载波、CPI、功率和通信
约束保持原配置。模型与近似、统计口径及否定条件见 [README.md](README.md)。
