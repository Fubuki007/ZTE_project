# RIS辅助毫米波通感仿真

MATLAB当前文件夹设为本目录，需要Optimization Toolbox。

- `main`：运行一次实验，输出真值、无RIS粗估计、RIS辅助精估计、RMSE、通信SINR和处理加观测总时长。
- `main_MC`：RMSE每点300次、输出SNR每点50次、运行时间每点50次；按文档参数点保存到`results`中的100个MAT文件，随后调用`plot_figures/plot_results.m`。
- `plot_figures/plot_results`：读取上述分点数据，显示文档中的8张RMSE、2张输出SNR和3张运行时间图。

## 参数与流程

物理参数：28 GHz载频、120 kHz子载波间隔、0.6微秒循环前缀；默认12672个子载波、每阶段256个符号、
16根发射天线、64根接收天线、256个RIS阵元、两个通信用户。
精估计、SCA和交替优化采用固定迭代次数，分别为10、8和4。
每次精估计从步长1开始回溯，接受首个使残差下降且位于局部区间内的更新。

`ris_sensing`依次执行：16QAM及ZF发射、回波生成、距离–多普勒检测与粗测角、RIS与发射波束联合设计、
两组RIS配置的四路径回波接收、RIS阶段回波投影及连续参数精估计。
粗检测未锁定时保留粗估计，该次实验仍计入统计。

RD检测及粗速度FFT峰值插值使用完整时频网格。
粗测角在全带宽和观测时段内均匀抽取384个子载波、64个符号；
精估计抽取256个子载波、最多64个符号，两组RIS配置各分配一半。
观测规模较小时使用实际可用样本数。
采样位置使用原始子载波编号和符号时刻，不缩短物理带宽或观测时段；抽取会减少积累增益。
四个抽取参数在build_default_params中直接配置。
RIS观测固定采用DD、RD、DR、RR四路径拟合。
精估计只拟合两组RIS配置的观测，每个目标对应4个路径复系数；
粗估计用于初始化和确定局部估计区间。
按文档流程拟合路径复幅度，构造有效雅可比，将实部与虚部堆叠后求解实参数最小二乘，并从步长1开始回溯更新。

## 扫描配置

| 图组 | 配置 |
|---|---|
| 接收阵列RMSE | N=3168，L=256，接收天线4/16，SNR=-50:5:10 dB |
| 观测符号数RMSE | N=12672，接收天线16，L=16/64/256，SNR=-60:5:10 dB |
| 接收阵列输出SNR | 接收天线9/25/49/100/196/400，SNR=10 dB |
| 观测符号数输出SNR | 符号数16/32/64/128/256/512/1024，SNR=10 dB |
| 发射天线运行时间 | 4/9/16/25/36 |
| 接收天线运行时间 | 9/16/25/36/49/64 |
| RIS阵元运行时间 | 4/16/64/256/1024 |

各组运行时间采用本组完整处理流程的实测值。

首次运行还会受到MATLAB即时编译等开销影响。

main中的“无RIS”表示原版直达回波粗估计，“RIS辅助”表示以相同粗估计为初值的RIS设计及精估计。两者性能差异包含连续参数精估计的收益。
## MAT数据格式

所有文件固定包含两种方法，`methods={'无RIS','RIS辅助'}`，并保留实验参数`p`。

- `rx_*_snr_*.mat`、`cpi_*_snr_*.mat`：`NMC`和`rmse`（2×4；行对应方法，列为距离、速度、俯仰角、方位角）。
- `snr_rx_*.mat`、`snr_cpi_*.mat`：`NMC`和`snr`（1×2，在线性功率域平均后转换为dB）。
- `runtime_tx_*.mat`、`runtime_rx_*.mat`、`runtime_ris_*.mat`：`Nrepeat`和`latency`（1×2，平均处理与观测总时长，单位s）。
