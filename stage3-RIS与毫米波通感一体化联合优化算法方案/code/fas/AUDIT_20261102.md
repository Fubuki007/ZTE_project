# FAS 弱收益复核：实现、搜索限制与定位信息

2026-11-02，北京时间。此次复核读取原正式实验的全部 3,900 个断点，未更换原实验代码或覆盖原结果。本地仅运行缩小规模的诊断冒烟；完整尺寸的回放和断点核对在服务器完成。

## 结论

未发现“FAS 坐标未进入回波或估计器”“结果汇总错位”“guard 更改了保留样本的噪声/符号”等问题。FAS 在正式样本中确实移动了天线、改变了信号并提高了照射能量。

当前实现检验的是小孔径内的发射端局部位置搜索，候选采用响应匹配波束，优化原照射能量。这不是定位导向的充分位置搜索，也不是流体天线可实现增益的上界。当前结果不能证明这个场景没有可利用的空间自由度。

## 全部正式断点的证据

- 核对原 manifest、样本身份、方法顺序、源码 SHA-256、位置约束、通信可行性和设计分数；全部通过。
- 从 3,900 个断点重算各方法位置 RMSE，与原 CSV 的最大绝对差为 `4.83e-13 m`。
- 3,900 个样本中 3,053 个通过粗估计锁定；这 3,053 个样本的四组设计均满足通信约束。
- FAS_RIS 在 3,053 个锁定样本中有 3,043 个发生移动；每样本最终移动阵元数中位数为 12/16，接受移动次数中位数为 17（同一阵元可在两轮中移动两次）。
- 每样本最大阵元位移中位数和最大值均为 `0.2828427 lambda`。每个坐标轴至多移动 `0.2 lambda`，二维对角位移可达 `sqrt(2)*0.2 lambda`。
- FAS_RIS 相对 Fixed_RIS 的最终照射分数改善中位数为 `3.3383%`；范围为 `-0.0391%` 至 `27.5212%`。不同局部优化轨迹不保证 FAS 优于固定组最终解；各自保存的迭代历史均未出现超过 `1e-8` 的分数下降。
- 原位置与选定位置的目标发射导向矩阵相对变化中位数为 `26.07%`；RIS 馈入响应相对变化中位数为 `54.05%`。这是复向量差异，不能直接解释为定位精度收益。
- 每样本取两目标中较小的归一化导向相关系数，其中位数为 `0.94953`，最小值为 `0.81390`。这是选定阵列与原阵列的相关性，并非所有候选端口的空间相关函数。
- 847 个样本在粗估计阶段未锁定，没有执行任何组的精设计或精估计。其中 -50 dB 和 -45 dB 各 300 个样本全部如此，因此这两个 SNR 点四组重合不能用于判断 FAS 作用。
- guard=4 时正式精估计使用的样本数由 `256*64=16384` 减为 `256*63=16128`；保留采样点的符号、噪声和绝对时刻一致。

## 六项解释逐条核对

| 解释 | 核对结果 |
|---|---|
| 只动 Tx，角度由 Rx 决定 | 前半句成立。后半句过强：精估计模板也包含 Tx 响应及其角度导数，Tx 仍可改变照射 SNR 和波形中的角度信息；固定 Rx 并不使 Tx 的定位贡献恒为零。 |
| 孔径 1.5 lambda，移动约 0.2 lambda | 成立，须区分每轴 0.2 lambda 与二维最大 0.283 lambda。这是实际执行的局部搜索范围，不能代表整个孔径内所有位置组合。 |
| 信道太干净、相关性高 | 当前是确定几何的直达/RIS路径，没有丰富随机散射；但观测到的响应并非完全相同。不能为制造收益而给每个端口独立抽信道，也不能由相关性高直接推断定位收益上界近零。 |
| 优化能量而非定位误差 | 成立。算法未直接优化 PEB、有效 Fisher 信息或定位误差。 |
| 近似候选评估、局部搜索 | 成立，且是重要算法限制。候选不逐个进行充分波束/RIS重优化，而是先用最小范数响应匹配构造波束，再评估能量和通信约束。 |
| guard 抵消收益 | 成立但不是全部原因。原正式结果在 -20 至 10 dB、零 guard 下也仅有约 1.55%–2.27% 的位置 RMSE 改善。 |

## 响应匹配具体限制了什么

`fas_transport_beams` 中，设 `A_old`、`A_new` 的列为各目标、RIS、通信用户的响应，波束由

```
W_raw = lsqminnorm(A_new', A_old' * W_old)
W_new = W_raw / norm(W_raw, 'fro')
```

生成。当响应匹配线性方程可解时，所有被匹配方向的复输出只会乘以同一实数增益（每个配置各一个）。在上述三个样本中，每个阵元选取一个合法非零邻域候选，匹配相对误差最大约 `3.8e-16`，确实接近机器精度。

因此候选评估主要检查新几何能否用更少波束范数保持原有响应，归一化后得到能量改善。它会主动保留原有方向输出之间的比例，并未充分寻找更有利于区分位置的响应。后续仍会重新优化波束/RIS，位置也会改变角度导数，因此不能将这一性质解释为整个算法的信号完全不变。

从量级看，如果只有照射 SNR 改善，且处于 RMSE 随 `1/sqrt(SNR)` 变化的区域，3.34% 能量改善对应约 1.63% RMSE 改善。这仅是解释小收益的示例，不是本多目标系统的精确公式或上界。

## 下一步应解决的问题

需要比较同孔径、同功率、同时间预算、同先验下的有效定位信息，而非继续仅按照射能量选位置。固定阵列也应允许充分波束/RIS优化，并加入离线优化固定非均匀阵列的对照，避免把“改了一种阵列排布”归因于在线 FAS 自适应。

先做定位导向的候选诊断和更充分的参考搜索，明确未知路径幅度、粗估计误差及切换/训练开销。真值辅助结果只作潜力诊断，不能作为可部署算法性能。若缺少经过证明的松弛界或其他认证界，充分搜索的最佳结果也仍是参考结果，不能称为理论上界。

“信道几乎一样”不足以证明定位信息一样：还需比较信号对位置的导数，以及消去未知幅度等参数后的信息矩阵。例如不同阵元坐标在正侧向可能产生相同的平面波相位值，但相位对角度的导数仍随坐标改变。
