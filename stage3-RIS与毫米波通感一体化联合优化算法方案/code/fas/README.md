# MATLAB Stage-3 流体天线增量收益实验

唯一算法基准是本目录上一级的用户提供 MATLAB 代码。原始版本已备份到
`codex/pre-matlab-fas-20261023`，提交 `8dcf95f25fd70e948e347b12f6d25b660e164f90`。
未移植或套用 Python Stage-3 的单用户、64RIS、总256符号及归一化反射幅度模型。

## 要回答的问题

比较固定天线/流体天线 × 无RIS/有RIS的四组实际定位误差。
主比较为 FAS_RIS 对 Fixed_RIS；FAS_noRIS 对 Fixed_noRIS用于识别RIS存在时的差异。
以三维位置RMSE及配对95%区间为主，另报距离、速度、角度、5m定位失败率、通信可行率。
算法均优化原 max-min 照射能量，并沿用同一个联合精估计器；不能把结果解释为最优定位设计的极限。

## 正式参数与明确假设

- 28GHz、12672子载波、120kHz间隔、16Tx/64Rx、256RIS、2bit、2用户、10dB SINR。
- 每阶段256符号，总512符号；保留原16QAM、距离/多普勒检测和RIS物理几何幅度。
- 完整RD网格；粗测角384子载波/64符号，精估计256子载波/64符号。
  这些是原代码已有抽样，不把“全量”解释为精估计使用全部12672×256样本。
- 正式默认300MC × SNR=-50:5:10，共3900个配对样本。每个MC重新按原分布生成目标，
  相同MC在不同SNR复用几何，所有方法共享同一粗估计、噪声方差及重叠采样点的QAM/噪声。
- Tx端口在原阵列xy范围 `[0,1.5λ]²` 内，16个激活天线/RF链不变，Rx固定。
  候选端口0.1λ网格，激活天线间距至少0.4λ，局部坐标搜索2轮，每轮移动一个网格邻域。
  固定阵列保留原0.5λ间距。这里检验相对原固定阵列的端口自适应收益，
  未证明优于所有离线优化的固定非均匀阵列，也不声称端口搜索全局最优。
- 原代码采用中心频率空间导向与宽带时延；该近似对所有组一致。端口信道按共同几何生成，
  不为每个端口独立抽衰落。沿用无互耦、理想校准的假设，0.4λ间距下硬件效应尚未验证。
- 先共同粗估计，再选择一组Tx位置并在整个精估计阶段保持；两组RIS/波束使用同一Tx位置。
  不使用测试真值设计；已知通信信道、几何模型及端口校准沿用原假设。
- FAS主图预留4符号切换/稳定/校准预算，并保存0、16符号敏感性结果。
  预算是待硬件标定的假设，不是实测切换速度；零开销只是理想参考。
  守护时间从固定512符号总窗口中扣除；删除相应fine样本，保持剩余样本的原始时刻。
  Fixed可使用全部精估计窗口。FAS消耗的无线发射能量不超过Fixed；未标定额外电控能耗。
- 离线优化时间独立记录，不宣称在约4.57ms的观测窗口内完成计算与闭环控制。
  不额外模拟扫描测量训练；若器件需要逐端口CSI探测，必须增加探测协议和预算后再作实用主张。
- 原精估计只使用第二阶段，原粗估计用于初始化；四组相同。
  固定与FAS拥有相同次数的波束/RIS优化。无RIS通过将物理反射响应置零实现。
- 粗估计未锁定或通信不可行时保留粗估计并记失败，不删除该样本。
  5m为预先声明的整次试验失败阈值（任一目标超过5m），同时保存逐目标连续误差。

## 文件与运行

`fas_optimize_array.m`复用原SOCP/SCA与离散相位优化，在两配置共同的端口位置上搜索。
端口候选用最小范数响应匹配同步调整波束，再按原通信/功率约束和照射目标接受；
固定组也执行同位置的响应匹配，两组均再进行相同轮数的原波束/RIS优化。
`fas_run_case.m`运行配对四组及开销敏感性；`run_fas_experiment.m`原子保存逐样本MAT断点。
`aggregate_fas.m`按MC整体配对bootstrap 2000次，输出CSV、增益区间与四指标图。
`status.py`读取真实断点和worker状态；`run_server.sh`负责进程锁、日志及完整汇总。

MATLAB内进入本目录执行：

```matlab
test_fas
run_fas_experiment('smoke',fullfile(pwd,'results_smoke'))
```

本地仅允许smoke，缩减参数明确记录，不能作为性能结论。
正式服务器使用仓库 `tools/ris-fas-matlab-server.ps1` 的 upload/test/run/status/fetch。
每次上传使用新的Git提交号作为独立release目录；运行中的代码不会被后续修改覆盖。
重启时相同配置、源码哈希和样本身份才允许复用断点。
仅在所有样本完成且汇总成功、`state=COMPLETE` 时表示正式实验完成。
