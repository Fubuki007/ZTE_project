# FAS收益受限原因：直达衰减与固定布局对照

以用户指定Stage-3为基准，使用已完成正式实验的300个几何及其10 dB输入。写代码前已推送备份分支 `codex/pre-fas-mechanism-20261104`，核对远端SHA `ffc7e32f0cd4b59d74335836bcf047a79b429afe`。备份包括源码、脚本、文档和已选结果；环境、凭据、缓存、历史未选文件及大批原始MAT排除。

## 本轮问题

1. 当前强直达、弱RIS项是否限制位置自适应？削弱直达链路后，RIS和FAS的相对定位信息收益是否改变？
2. 同孔径固定非均匀布局能否获得类似收益，是否确实需要在线位置自适应？
3. 相对信息改善能否转化为实际精定位误差改善，切换开销及绝对精度是否仍可接受？

## 正式规模与不变资源

- 300个原始几何 × 5档DD往返功率损耗（0、20、40、60、80 dB）=1500组；每组7种结果。
- 本轮固定原输入标定SNR=10 dB，检验机制而非重画原13点SNR曲线。固定发射功率和原噪声方差，**不随衰减重新归一化噪声**。
- 保留原16Tx/64Rx、256RIS/2bit、12672子载波、粗256+精256符号、原时频抽样、通信SINR、0.1λ端口及0.4λ最小间距。各发射布局均在同一 `[0,1.5λ]^2` 内，不增加RF链或孔径。
- 本地仅smoke；服务器先完整尺寸数学检查和0/80 dB端点pilot，再启动正式1500组。8个worker，每个最多2计算线程；逐样本MAT、种子、噪声标定、设计、日志和真实进度保存。

## 衰减模型与先验

设DD往返功率损耗为A dB，单程BS—目标链路幅度系数 `h=10^(-A/40)`。四条路径DD、RD、DR、RR的额外幅度系数为 `[h^2,h,h,1]`。它模拟同一BS—目标链路的互易衰减，单次经过该链路的RD/DR也衰减；未人为增强RIS。目标—RIS、BS—RIS及用户通信链路不施加此受控衰减，属于明确的实验假设。

所有对照共享**原未衰减10 dB实验获得的粗定位先验**，然后在衰减后的新精定位回波上优化和估计。它是有共同外部/历史先验的条件精定位诊断；**不验证遮挡条件下重新粗定位的成功率，也不能称为完整遮挡端到端性能**。高损耗下RMSE可能主要受这个先验和估计器局部区间限制，必须同时查看初始先验RMSE、PEB、绝对误差和失败率。

设计仅使用共同粗估计、等幅名义目标系数和本轮已知的衰减档位；真值和真实幅度用于评价。沿用每目标4个、跨两配置共享的未知路径复系数估计，不把反射相位当已知真值。原估计器的自由路径复幅度可吸收固定衰减，无需改写精估计器。

## 对照和算法预算

- Fixed_uniform_RIS：原4×4均匀固定布局，优化波束/RIS。
- Fixed_edge_RIS：预先指定的 `[0,.4,1.1,1.5]^2 λ` 固定非均匀布局，仅优化波束/RIS，布局不读取样本真值。
- FAS_RIS_guard0/4：同时优化位置、波束和RIS，保留两个固定布局的可行解；同一设计评价guard0和guard4。
- Fixed_uniform_noRIS：相同均匀固定布局，关闭RIS路径，重新优化波束并满足相应通信约束。
- FAS_noRIS_guard0/4：关闭RIS后允许同孔径位置自适应，作为RIS协同收益对照。

每种实际设计3个初值、每段最多40次SQP。RIS开启时1轮离散相位搜索；关闭时相位无效，省略该搜索，固定/FAS均如此。非均匀布局若响应匹配初值不满足通信约束，用该布局下的零迫通信波束构造可行初值。所有设计计实际耗时和求解状态，不声称全局最优或等计算耗时。

guard4沿用既有4符号假设，未硬件标定。发送位置以合法网格用于实际回波和估计；连续解仅作诊断。

## 验证与结果

`test_mechanism`检查0 dB时与原回波一致、互易路径衰减、幅度整体缩放、衰减回波的独立差分FIM及位置/波束梯度。服务器还用完整尺寸原断点运行同样数学检查。原默认信息模型继续接受既有 `test_loc_information` 检查。

`aggregate_mechanism`要求每档300次全部完成，重算坐标误差并核查孔径、网格、功率/SINR、相位量化、保留固定布局及接受步单调性；检查同一几何在所有损耗/方法中噪声方差和粗先验误差相同。输出RMSE、初始先验误差、失败率、PEB、径向/角度位置误差下界、分路径功率指标、搜索状态及配对置信区间。Inf PEB保留计数，不删除不可辨识设计。分路径功率比为独立等功率数据流下的隔离路径功率和，不含相干交叉项。

主要比较FAS对均匀固定布局和固定非均匀布局的收益，并对照无RIS情况。不能把相对增益变大等同于绝对精度可用，也不能把共享先验下的结果推广为遮挡重新捕获性能。
