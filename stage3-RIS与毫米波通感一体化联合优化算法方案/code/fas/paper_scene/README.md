# 论文启发的弱直达、散射信道FAS实验

目的：检验Jiang等2021年IRS-DRC论文所强调的弱直达与散射环境中，同孔径发射位置自适应是否比充分优化的固定阵列更有价值。本实验是模型适配和潜力诊断，不是该文数值曲线复现，也不作为实际定位RMSE的证据。

## 来源与改动

- 唯一参数基准仍为本项目Stage-3 `build_default_params.m`：正式保留28 GHz、16Tx、64Rx、256RIS、2bit相位、12672子载波、粗/精各256符号、精阶段256子载波和64符号抽样。Tx同在`[0,1.5lambda]^2`内，0.1lambda网格，至少0.4lambda间距，RF链、总功率1、接收阵列均不增加。
- 采用论文的一目标、一通信用户与DD/RR两路径，替代原来的两目标、两用户和四路径；这是明确的场景变更。目标采用原目标生成器的第一个目标，距离约600m；RIS相对BS为`[100,0,0]m`，用户为`[100,0,-1]m`，对应论文BS/IRS同高、用户在IRS下1m的拓扑。目标方向、距离取项目几何，未同时强行指定论文中与坐标未必一致的独立角度。
- 直达目标系数0.01，IRS目标系数0.1，取自论文仿真设置；它们是两个归一化通道项的幅度系数，不能直接解释为现实覆盖链路预算。论文的BS-IRS莱斯与用户瑞利衰落，扩展为32条固定平面波的空间场：FAS移动时所有角度和复系数保持不变。Tx/Rx共用同一BS-IRS散射实现；共位置端口的G严格一致。未为每个候选端口独立抽取随机信道。
- 三档：Rayleigh、Rician K=10dB、纯LoS；每档300个配对种子，共900组。跨K使用相同目标和散射随机数，跨方法共享同一完整场。纯LoS仅指BS-IRS链路；用户直达链路仍采用同一多径场。
- 采用论文的Hermitian复数通道约定：`H=.01*arx*atx' + .1*(Grx'*(v.*a))*(Gtx'*(v.*a))'`；没有引入多RIS反复反射。

## 必须保留的归一化说明

论文对G的莱斯NLoS项与大尺度衰减的组合存在复现歧义；若将其打印的0.1解释为阴影功率系数，按各链路损耗、P=3W、噪声0.1直接计算，16Tx无IRS的用户MRT SNR约-53dB，无法满足10dB门限；不能直接把这套量纲与原项目归一化噪声混用。`scene.printed_link_budget`保存这一独立可行性检查，并不当作论文曲线错误的证明。

本轮是明确的增益归一化诊断：每个几何/K，在**固定均匀参考阵列**上将G的Frobenius范数归一至sqrt(16)，用户直达向量归一至sqrt(16)，h1单位方差。其标量此后对所有候选位置和方法固定，Rx采用同一G标量；不按移动后信道重新归一化。雷达噪声0.1、通信噪声沿用项目0.05、通信SINR门限10dB、功率1固定。不同K也具有相同的参考G总增益，使对照集中于空间结构。未采用论文物理路径损耗得到现实覆盖或精度结论。

## 对照和优化预算

1. 均匀固定RIS与预先指定的非均匀固定`[0,.4,1.1,1.5]^2`RIS各作4轮波束/离散RIS优化。
2. 选择其中SNR较好的固定布局，追加4轮优化，得到`Fixed_best_RIS_refined`，用于排除FAS仅因多做几轮波束/RIS优化而获益。
3. FAS从同一初始固定方案出发，追加相同4轮，并加入每轮最多40步的连续位置SQP；落到合法端口后才评估和接收。保留精化固定方案为可行下限。记录实际迭代标志、控制、位置、单调接受轨迹和耗时；不声称全局最优或计算量相等。
4. 无RIS均匀固定/FAS作为协同对照；所有方法都满足相同的单用户通信与功率约束。单用户固定控制下的波束采用特征向量/对偶二分，位置改变时重解波束。
5. FAS同时报告guard0和guard4。功率SNR不扣guard；净积累能量指标扣除精阶段256符号中的4符号；定位下界移除相应原始符号时刻的精阶段抽样，不重标时间。

## 指标与结论边界

- 主指标为论文的**窄带雷达接收SNR**，目标和信道已知，属于oracle设计。主要比较`FAS_RIS_guard4`与`Fixed_best_RIS_refined`，同时保留均匀/非均匀固定对照。
- 补充指标是宽带DD/RR扩展模型的三维位置误差下界PEB：显式使用项目原时频样本位置和多普勒，消去两个未知路径复幅度。单流单位平均符号功率下的期望Fisher信息用精确时频Gram计算；未假装生成完整OFDM观测或沿用原四路径估计器。原有粗阶段256符号仍保留在总512符号预算中，此诊断不执行粗捕获。
- PEB使用真实目标参数、已知散射场，未包含散射场估计误差；无法提供实际定位RMSE。原论文窄带SNR目标不等于PEB目标，因此PEB可能变差。较大SNR增益不能单独证明定位值得加入FAS。
- 纯LoS/强散射均需报告全部300个样本及Inf PEB数量；配对bootstrap按几何抽样。所有样本保存，不因指标不佳而丢弃。
- 四符号开销未硬件标定，未计逐端口信道探测、场校准和计算闭环延迟。归一化和oracle假设使结果只能判断条件下的潜力，不能声称真实部署已验证。
