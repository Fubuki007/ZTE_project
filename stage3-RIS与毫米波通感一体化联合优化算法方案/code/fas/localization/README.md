## 要回答的问题

1. 原回波与有效定位信息的计算是否一致？如不一致，先修复并验证。

## 模型与资源

- 全量沿用 28 GHz、16 Tx/64 Rx、256 RIS/2 bit、2 用户、12,672 子载波、粗256+精256符号。
- 沿用原粗估计、精估计、时频抽样、投影、16QAM、噪声标定和四路径未知复幅度模型。
- 16个激活发射端口和RF链，位置范围 `[0,1.5 lambda]^2`，最终端口在0.1 lambda网格，最小间距0.4 lambda。
- 发射功率约束为每配置 `norm(W,'fro')<=1`，通信SINR门限10 dB；接收阵列固定。
- FAS同时报guard=0和guard=4；总512符号窗口固定，保留原时刻和共同采样点的符号/噪声。优化按guard=0进行，guard=4是同一设计的净收益检验。
- 连续位置只用于参考搜索和量化前诊断，实际RMSE仅使用合法离散端口。SQP约束采用0.400001 lambda的数值余量，以满足原位置验证器的0.4 lambda硬约束。
- 仍采用原中心频率空间响应、宽带时延、无互耦和理想校准。端口探测和切换成本仍未经过硬件标定，计算时间独立记录，不声称实时闭环。

## 定位信息

`loc_information_cache` 将原投影观测及其位置导数作不损失列空间信息的QR压缩，避免每个候选重复生成完整时频回波。
`loc_information` 消去每目标4个、跨两个配置共享的未知复幅度，用有效Fisher信息计算平均三维位置误差平方下界，再开平方得到PEB。
奇异信息矩阵返回无穷大，不能用伪逆把不可辨识方向报告成零误差。

缓存固定设计位置和投影基，控制变量改变时更新发射响应、角度导数、RIS响应及波束。
模型导数、缓存FIM、log(PEB)对波束和位置的伴随梯度、通信/间距约束梯度均用原物理回波或中心差分独立核验。
PEB只是给定局部参数与设计的下界，搜索得到的最好设计也不称为全局最优或增益上界。

## 对照与搜索

- 旧 Fixed_RIS、旧 FAS_RIS（guard0/4）直接复用原正式断点作参照。
- Fixed_localization：固定阵列，优化log(PEB)目标下的波束和2bit RIS。
- FAS_localization（guard0/4）：增加原孔径内位置变量，最终量化到合法端口，重优化波束。
- 每组3个初值，每个初值按相同40次SQP迭代上限进行初始优化、一次RIS离散逐阵元搜索、再次SQP及最终固定位置波束优化。逐候选采用实际PEB而非照射能量。
- FAS包含固定阵列定位设计、旧FAS设计、向孔径边缘分布的 `[0,.4,1.1,1.5]^2` 布局作为初值；连续阶段允许移动至整个孔径。固定组使用旧设计、另一波束初值及确定性波束扰动。
- 响应匹配只可用于构造初值，候选随后进行定位目标下的约束优化，不再将响应匹配能量当作位置优劣标准。
- FAS复用已求得的固定阵列方案作为可行下限；两组具有相同的优化轮数上限，但实际迭代次数、候选数、耗时可能不同，全部保存。无线资源相同不等于计算量完全相同。
- 可实现设计仅使用共同粗估计及等幅名义目标系数，不读取测试目标真值或真实回波幅度。计算实际PEB和仿真评价时才使用真值。
- 10 dB下全部300个几何另运行双方都知道真值和幅度的参考搜索，只作潜力诊断，不计入可实现方法结果。
