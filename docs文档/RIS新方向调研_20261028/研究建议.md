# 当前 Stage-3 系统的替代方向：先解决弱反射支路，再验证定位收益

日期：2026-10-28。基准为当前分支的 **MATLAB 原方案及已完成的 FAS 配对实验**，不是另一套 Python AI 模型。本文是代码复核和定向文献筛选；没有实现新方案，也没有产生新的 RMSE 仿真结果。

## 1. 推荐判断

如果允许改变 RIS 硬件，**优先筛查“有源 RIS + 噪声感知的定位信息设计”**，其次是“半无源/混合感知 RIS + 基站与 RIS 联合接收”。这两条路线分别针对反射支路衰减和接收信息来源，机制比继续调整 Tx 端口或学习原照射目标更直接。

如果必须保留全部原硬件，优先做 **消去未知路径幅度后的定位信息设计**，并把粗、精阶段的可用观测联合利用。它与当前估计器衔接最紧，但不能预先保证明显收益。

“明显提升”应通过相同资源下的实际 RMSE、失败率和配对置信区间判断。论文里的单目标角度 CRB 改善，不等于本工程双目标距离、速度、两角度和三维位置 RMSE 必然一起改善。以下均为候选机制，未宣称新颖性已经通过穷尽查新。

## 2. 当前系统有两个必须先看清的限制

### 2.1 反射系数本身很小

`channel_geometry.m` 中，一个 RIS 阵元相对于直达支路的反射幅度因子为

\[
g=\frac{d^2}{\lambda}\sqrt{c_i c_o}\frac{R}{d_{BR}d_{RT}},\qquad
c_q=\sum_{n=1}^{256}\phi_n V_{nq}.
\]

因为被动相位满足 `|phi_n|=1`，必有 `|c_q| <= sum_n |V_nq|`。代入默认目标均值、28 GHz、16×16 RIS、基站到 RIS 20 m：

| 默认目标 | 理想连续相位下的 `|c_q|` 上限 | `|c_q|²` 上限对应 dB |
|---|---:|---:|
| R=600.8 m，theta=24.63°，phi=30.99° | 0.018865 | −34.487 dB |
| R=600.2 m，theta=15.94°，phi=13.58° | 0.020947 | −33.578 dB |

这是**RIS 标量系数的代数上界**，使用未加随机扰动的代表位置；不是已运行样本的平均值，也不是整条回波相对 DD 的精确 SNR。实际 RD/DR 与 DD 的比较还取决于波束照射、接收阵列、目标散射和相干叠加。2 bit 量化、双目标和通信约束通常会进一步限制对齐。

当前 `fas_echo.m` 中，单次经过 RIS 的 RD/DR 项乘 `c_q`，两次经过的 RR 项乘 `c_q²`。因此先优化一个很弱的反射分量，可能难以改变总定位信息。需要先核算各路径的实际能量和有效信息，不能直接用放大倍数替换物理链路预算。

### 2.2 现有 RIS 基线也有改进空间

已完成的 300 MC/SNR 结果如下，单位为三维位置 RMSE（m）：

| SNR | 固定阵列无 RIS | 固定阵列原 RIS |
|---:|---:|---:|
| −35 dB | 22.036 | 26.241 |
| −30 dB | 2.743 | 4.111 |
| −25 dB | 1.513 | 1.767 |
| −20 dB | 0.867 | 0.920 |
| 0 dB | 0.08541 | 0.08366 |
| 10 dB | 0.02629 | 0.02569 |

来源为已提交的 `server-results/matlab-fas/aafa68081d27ee7b0fb379f4823c9fb48ea06194/full_mc300_20261023/metrics.csv`。这里列出实际点估计，不以这些数值单独宣称统计显著性。FAS 相对原 RIS 的额外位置收益为 −0.534%～2.183%，13 个 SNR 中 11 个配对 95% 区间包含零。

原方案优化的是**最弱目标的照射能量**。精估计却需要从两组配置里，拟合每个目标四个独立未知复路径幅度和四类运动/位置参数。弱路径引入的额外待估量、局部模板相关性、粗估计误差都可能影响中低 SNR 表现；尚不能把差异唯一归因于其中一项。

还有一个协议限制：当前粗估计在 RIS 关闭时完成；`fas_run_case.m` 只有在 `coarse.locked` 为真时才进行设计和精估计。−50、−45 dB 的所有方法因此输出相同结果。**只修改精估计阶段的 RIS，无法挽救这些已经跳过精估计的样本。** 若研究低 SNR/直达受阻收益，必须同时设计 RIS-on 捕获，或利用先验启动；新协议要计入同一个 CPI，不能给新算法真值初值。

## 3. 方向一：有源 RIS + 定位信息设计

**通俗理解：给可调反射面增加受控放大能力，让原来很弱的反射支路有机会真正参与估计。**

当前单元系数为 `exp(j theta_n)`，有源版本为 `a_n exp(j theta_n)`，其中幅度、相位、输出功率和放大噪声都受约束。第一版保持原 2 bit 相位，新增幅度范围/量化另行记录；不能同时放宽相位精度而混淆收益。链路仍可保留 DD/RD/DR/RR，但需要重新构建经过一次、两次有源 RIS 的信号与噪声模型。

接入链路：粗位置/不确定区域 → 联合设计基站波束和 RIS 幅相 → 收集带放大噪声的多配置回波 → 对联合噪声协方差白化 → 四路径联合估计 → 距离/速度/角度/XYZ RMSE。

优先受益场景是反射回波太弱、直达回波减弱或多目标照射受限。其直接作用是改善有效回波质量；如果误差来自模型失配或错误初始化，单纯放大不保证改善。特别是原粗估计跳过的样本，需要前述捕获协议修改。

必须核算：基站和 RIS 的总能量、RIS 射频输出与电路功耗、增益上限、噪声系数、带宽及稳定性。RR 不能简单当成“有源系数平方 + 原白噪声”；多次经过放大器产生的噪声、时间关系和相关性需要推导。SNR 横轴继续采用共同的参考噪声/输入标定，不能按各方法增强后的回波重新归一化噪声。

建议同时给出“同基站功率、额外 RIS 用电”和“同基站+RIS 总能量”两种比较，明确前者的硬件投入；没有瓦特级标定前，只能报告归一化预算敏感性。

核心论文 [1]：Qi Zhu、Ming Li、Rang Liu、Qian Liu，**Cramér-Rao Bound Optimization for Active RIS-Empowered ISAC Systems**，IEEE TWC，2024，DOI [10.1109/TWC.2024.3384501](https://doi.org/10.1109/TWC.2024.3384501)。核查了 Crossref 元数据和 OpenAlex 摘要。论文联合设计基站预编码和有源 RIS，在通信 SINR 约束下优化 DoA CRB；本文尚未获得该文全文，未引用其具体仿真增益或声称其模型可直接照搬。

## 4. 方向二：半无源/混合感知 RIS + 联合接收

**通俗理解：在反射面上放少量接收通道，让它也能听目标回波，再与基站收到的回波一起定位。** 这里的“有源传感器”指接收传感器，和方向一的反射放大器不同。

原有 RR 链路是：基站 → RIS → 目标 → RIS → 基站。

文献中的新增接收链路是：基站 → RIS → 目标 → RIS 上的传感器。若直达照射可见，还应同时建模基站 → 目标 → RIS 传感器。新增回波经采样、标定和传输后，与原基站观测联合估计；不能只把两份最终角度做无权平均。

潜在收益来自少一次返回反射/传播，以及不同位置或接收孔径提供的信息。但当前 RIS 距基站仅 20 m、目标约 600 m，两站视角可能接近；**不能把它宣传成已有很长基线的三角定位系统**。是否值得放 4/8 个接收通道，应先计算传感器几何、路径预算和新增位置有效信息。这些数目只是建议筛查点，不是已验证配置。

公平对照至少包括：原 64 路基站接收；增加 RIS 侧接收；同样额外通道放在基站的对照。区分额外传感器安装和替换反射单元两种架构，计入有效面积、接收功耗、同步与回传成本。跨站未知时钟、频偏和相位应作为 nuisance 参数或有开销的标定量；不能默认全部已知。

核心论文 [2]：Qiaoyan Peng 等，**Semi-Passive Intelligent Reflecting Surface-Enabled Sensing Systems**，IEEE TCOM，2024，DOI [10.1109/TCOMM.2024.3399202](https://doi.org/10.1109/TCOMM.2024.3399202)，[公开稿](https://arxiv.org/abs/2402.03042)。核查摘要、系统模型相关段落、点目标数值讨论及条件性比较。研究包括点目标 DoA CRB、扩展目标响应矩阵和反射/接收单元分配；不是本系统宽带双运动目标 RMSE 的直接证明。

重要反证 [3]：Xianxin Song 等，**Fully-Passive Versus Semi-Passive IRS-Enabled Sensing: SNR and CRB Comparison**，IEEE TWC，2025，DOI [10.1109/TWC.2025.3577298](https://doi.org/10.1109/TWC.2025.3577298)，[公开稿](https://arxiv.org/abs/2311.06002)。核查摘要、接收波束比较、CRB 分析适用条件及结论：在其单目标 NLoS/ULA 模型下，反射单元足够多时，全无源方案可凭额外返回波束增益超过半无源方案。因此不能只凭“少一跳”保证收益，也不能直接移植其 N 阶缩放律到本工程。

硬件佐证 [4]：Idban Alamzadeh、Mohammadreza F. Imani，**Experimental Demonstration of Sensing Using Hybrid Reconfigurable Intelligent Surfaces**，Sensors，2025，DOI [10.3390/s25061811](https://doi.org/10.3390/s25061811)。仅核查元数据和摘要；有 AoA 实验原型，不能当作当前被动目标全链路定位实验的证据。

## 5. 方向三：保留硬件，直接优化定位信息

当前算法问的是“哪个配置让最弱目标更亮”；建议改为“哪个配置让相近位置更容易区分，而且这种变化不能被未知路径幅度冒充”。

`refine_ris_parameters.m` 已有关键步骤：构造路径字典 D、位置/速度导数 G，并投影掉可由未知复幅度解释的导数。在已白化观测域，可构建

\[
J_{\mathrm{eff}}=2\operatorname{Re}\{G_w^H(I-D_wD_w^\dagger)G_w\}.
\]

随后还要消去速度等非目标参数，把距离/角度协方差正确转换成 XYZ，才能得到位置误差下界 PEB。角度使用度还是弧度必须一致，奇异时报告不可辨识，不能用伪逆伪造很小的 PEB。设计阶段评估 G 所需的路径幅度应来自粗估计或不确定集合，不能使用真值幅度和真值位置。

接入方案是：粗估计及不确定范围 → 两组 RIS/波束**联合**设计，使信息互补 → 使用实际已知符号、时刻、投影基计算信息 → 四路径联合精估计。原代码已经有两组优化配置，因此“加第二组”不是新内容；增加到四组也必须在同一 256 个精阶段符号和原样本预算下证明价值。

最小验证先保持两组配置和原估计器，只替换设计目标；随后分别消融粗精观测联合利用、弱路径筛选/幅度正则。粗精融合要保留各自波束、RIS 状态和绝对时刻，并处理初始化依赖；不能把用相同数据得到的粗估计再当成独立测量重复计数。物理共享路径系数需要目标散射依据，不能只为了降维强加。

适合多目标方向竞争、波束约束较紧、弱位置方向等情形。它比现有 AI 学习照射目标更贴近最终误差指标，但局部 CRB 不检测所有全局误锁，必须同时核查模糊峰、实际失败率和非真值初始化。

核心论文 [5]：Rang Liu 等，**SNR/CRB-Constrained Joint Beamforming and Reflection Designs for RIS-ISAC Systems**，IEEE TWC，2024，DOI [10.1109/TWC.2023.3341429](https://doi.org/10.1109/TWC.2023.3341429)，[公开稿](https://arxiv.org/abs/2301.11134)。核查公开全文中的摘要、贡献及模型段落。论文区分检测 SNR 和角度估计 CRB，以通信和速率为优化/约束内容；这里建议的双目标 XYZ 信息设计需要重新推导，不能直接把其角度公式当成全参数 RMSE。

相关论文 [6]：Zhen Wang 等，**RIS-Enabled Multi-Target Sensing: Performance Analysis and Space-Time Beamforming Design**，IEEE TWC，2024，DOI [10.1109/TWC.2024.3405575](https://doi.org/10.1109/TWC.2024.3405575)。仅核查元数据和摘要；研究空间波束与时间变化对精度、分辨能力的不同作用，以感知互信息设计。它支持研究配置互补，但不证明本工程配置数增加就会更好。

## 6. 备用硬件路线：BD-RIS

普通 RIS 每个单元独立调相，散射矩阵是对角的；BD-RIS 用可控互连让不同单元之间交换信号，散射矩阵可以非对角。这扩大了波前设计空间，有机会改善角度信息。

论文 [7]：Xiaoqi Zhang 等，**Beyond Diagonal Reconfigurable Intelligent Surface Enabled Sensing: Cramér-Rao Bound Optimization**，IEEE WCL，2025，DOI [10.1109/LWC.2025.3599590](https://doi.org/10.1109/LWC.2025.3599590)，[公开稿](https://arxiv.org/abs/2508.11292)。核查摘要、非对角酉矩阵约束说明、部署数值讨论及结论；原文主要为单目标角度 CRB，多目标和分布式场景列为后续工作。

本工程需要重构 BS–RIS–目标级联，不能用任意无约束稠密矩阵替代相位向量。还要指定互连结构、无源性、实际网络需要的互易约束、插损和可实现量化。当前反射标量很弱，互连硬件又复杂，故列为备用；“酉矩阵 CRB 优化”本身已有论文，不能单独宣称创新。

STAR-RIS 主要增加表面背侧覆盖；当前目标和反射面朝向未显示这类覆盖需求，因此本轮不优先。单纯增大带宽、CPI、面积或发射功率会改变资源预算，也不作为免费提升。

## 7. 如何避免再花几天得到重合曲线

1. **先做物理与信息筛查。** 保留原 16 Tx/64 Rx/256 RIS、12672 子载波和粗 256+精 256 符号，检查路径能量、消去 nuisance 后的信息、放大噪声/传感器开销及通信可行性。默认几何是主结果；直达减弱、方向接近等作为明确标注的压力场景。
2. **服务器先导只作筛选。** 使用完整物理尺寸，在失败过渡区、稳定估计区分别检查少量独立配对样本；提供完整脚本、参数和逐样本断点。先导不是正式 MC300 结果。正式 SNR 范围应在实验配置中单独锁定；已有 FAS 的 −50～10 dB 不能冒充新曲线覆盖。
3. **预先设验收标准。** 例如把“至少两个相邻 SNR 点的位置 RMSE 降低 20%，且配对区间排除零、通信可行性不退化”作为建议工程门槛。这是可调整的验收要求，绝非预测收益；角度、距离、速度、95% 误差和失败率仍需同时报告。单纯胜过较弱的旧 RIS 不够，还必须与固定无 RIS 和强固定阵列基线比较。
4. **通过后再做独立正式样本。** 对设计/估计器/硬件分别消融，使用共同场景和噪声种子，保存失败样本，不挑有利曲线。正式运行依然在服务器，本地只做冒烟；先导用于调参后不混入独立验证而不说明。

建议先后顺序：**先补齐强基线和预算诊断；允许硬件变化则筛查有源 RIS；优先增加观测能力则筛查半无源 RIS；原硬件不变则走定位信息联合设计。** 目前没有足够证据承诺任一方案在你的全部 SNR、全部参数上显著提高。
