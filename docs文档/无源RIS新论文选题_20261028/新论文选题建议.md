# 基于在审原方案的无源 RIS 新论文选题建议

日期：2026-10-28。用户确认原方案已投稿、审稿中。本报告将原稿视为已有工作，只筛选独立的新研究问题，不把原模型和算法重新列为新贡献。

**建议优先验证：弱路径可信度驱动的无源 RIS 多目标感知。** 备选是面向漏检/误锁的自适应探测协议。两者均保持无源 RIS、原阵列、原带宽和总 CPI；不需要 AI、流体天线、有源放大器或额外接收机。

这是选题与定向查新结果，不是已证明的新定理、已完成的性能提升或发表保证。本轮未运行新的蒙特卡洛或服务器任务。

## 1. 原稿已经有什么，哪些不能再算新贡献

基准文件是 `stage3-RIS与毫米波通感一体化联合优化算法方案/RIS 与毫米波通感一体化联合优化算法方案.pdf`，并与同目录 MATLAB 代码交叉核对。PDF 字体映射导致文字提取失真，因此实际渲染检查了第 3、8、10、11 页，以公式和完整页面为准。

| 原稿/代码已有内容 | 本轮核查依据 | 新稿处理方式 |
|---|---|---|
| 无源、离散相位 RIS 和宽带多目标回波 | PDF 第 3 页式(3)–(10) | 保留为已有模型 |
| DD/RD/DR/RR 四路径及共同几何约束 | PDF 第 10–11 页式(57)–(65) | 不宣称首次四路径建模 |
| 通信约束下最大化最弱目标照射指标 | PDF 第 8 页式(42)–(48)、第 10 页式(55)–(56)；`optimize_ris_joint.m` | 作为原稿设计基线 |

单独改成 CRB/PEB 目标、加 SBL/OMP、加 EKF、改 AO 求解器或复用粗阶段数据，均只能视为待评估的技术组件。新稿需要独立的问题、区别于近邻工作的结论，以及能排除替代解释的实验。

原稿 PDF 的指标使用分频响应；当前 MATLAB 的阵列导向采用中心载频近似。新稿若恢复逐频导向或绝对时刻一致性，应让所有对照共同获得这些修正，并把它们作为建模/实现核对，不能把修正本身包装为新发现。

## 2. 首选主线 A：弱路径可信度驱动的多路径利用

候选题目：

**《弱反射条件下无源 RIS 辅助宽带多目标感知：路径利用边界与自适应探测》**

英文工作题目：*Reliability-Aware Multipath Exploitation for Passive RIS-Assisted Wideband Multi-Target Sensing*。

### 2.1 一句话研究问题

**一条反射路径虽然存在，但弱到无法稳定估计时，应该怎样处理，才能降低最终位置误差？RIS 又该怎样探测，帮助判断并利用真正有价值的路径？**

原稿始终给每个目标拟合四个独立未知复路径幅度。保留弱路径可能增加估计不确定性；忽略实际存在的弱路径又会产生模型偏差。真正要研究的是这两种代价与 RIS 探测设计的相互作用，而不是简单设一个功率门限。

这与现有模型有直接联系：当前 `fas_echo.m` 的 RD/DR 项乘单次反射系数 c，RR 项乘 c²。此前针对默认均值位置的代数检查得到 `|c|` 理想上限约 0.019–0.021。该上限不是总回波 SNR，不能据此直接删路径；它只说明必须检查路径可测性。

已有 MC300 汇总在 −30 dB 给出的三维位置 RMSE 为：固定无 RIS 2.743 m，固定原 RIS 4.111 m。它是研究动机，不是已经证明损失来自弱路径。初始化、局部压缩和非线性求解也可能产生差异，必须逐项排查。

### 2.2 接入链路

```text
公共粗探测，得到位置/速度候选及不确定范围
    ↓
预算内的公共 RIS 探测，评估路径证据及路径幅度不确定性
    ↓
联合选择探测配置与估计模型/正则强度
    ↓
利用实际符号、绝对时刻和两组配置联合估计
    ↓
输出距离、速度、两角度、XYZ 及失败标志
```

第一版保持原两组配置和样本数，先比较固定四路径、若干物理合理的简化模型、幅度正则及自适应选择。对全模型采用连续收缩也可以，未必强制把路径硬删除。选择规则只用公共观测和先验；粗阶段 RIS 关闭，无法凭空知道全部反射路径幅度，因此所需 RIS 探测必须计入现有预算。

**估计器忽略路径，不等于物理路径消失。** 所有方法仍接收相同的真实四路径数据。不能为了让简化模型更好，就替它从回波生成器删除弱路径。原相位控制为单位模，也不能默认存在免费吸收/关闭状态。

### 2.3 三项需要新增、尚未完成的实质贡献

**贡献 A1：路径利用的偏差—方差边界。** 对固定观测模型，区分正确建模时未知幅度消耗的信息、遗漏弱路径引入的偏差，以及实际模型选择错误带来的风险。需要导出可计算的条件，说明路径强度、模板相关性、位置敏感方向和探测预算如何共同决定收益。

在已白化的观测域，固定路径集合 M 可用

\[
J_M^{\rm eff}=2\operatorname{Re}\{G_M^H(I-D_MD_M^\dagger)G_M\}
\]

作为局部分析起点，之后消去速度等参数，并转换到 XYZ。**这个投影公式本身是已有方法，不是拟主张的新定理。** 它也不能单独比较漏路径模型：后者存在偏差，应使用适当失配分析或经验证的一阶风险近似。CRB 不是有限样本 MSE 上界，选择后 CRB 也不能直接冒充完整选择风险。

一个需要核查的非正则细节是：弱字典列缩放得很小，其张成空间未必相应缩小；实际的幅度先验、正则和数值秩阈值会改变结果。代码 `pinv(D,1e-8)` 的截断不能充当物理可测性标准。应核查归一化、噪声和数值秩的敏感性，不能把病态参数化制造的现象说成所有 RIS 的物理规律。

**贡献 A2：配置设计与路径可信度共同决定。** 不把可用路径集合当成真值输入；利用同一预算内的观测判断是否能可靠区分路径及位置，并让波束和 2 bit 相位降低最坏位置风险。设计目标需要同时考虑遗漏代价和未知幅度造成的信息混淆，而不是只优化选定模型的局部 CRB。

真正可能形成差异的是“探测改变路径可判定性，路径判定又改变应当优化的定位信息”这一闭环。如果实现只是 BIC/SBL 选路径，再运行普通 CRB-AO，尚不能认定新颖性充分；需有新的可解条件、结构或算法性质，并与该组合基线比较。

**贡献 A3：证明收益由什么产生，并给出不值得使用的边界。** 同时比较检测/选择错误、定位误差、通信可行性和开销，检验是否真正获得额外有效信息。不能只展示选定模型的更低 CRB，或者只与较弱的旧估计器比较。

这三项是候选研究任务，当前没有完成推导和性能验证。

### 2.4 为什么它有机会成为独立新稿

原稿解决给定四路径结构下的照射设计与参数估计；A 研究的是**有限噪声和预算下，路径利用方式未知时的风险与探测决策**。其独立性需要由边界分析和闭环实验建立。

[1] 已研究未知增益引起的信息损失；[2] 已把相干性、检测与 RIS 分辨能力联系起来；[3] 已利用不同阶次路径并分析检测。因此不能宣称首次认识“多径有利也可能有害”，也不能仅增加一个 EFIM。需要进一步确认是否已有文献完整覆盖“物理四路径、弱路径不确定性、遗漏偏差和探测设计共同作用”的同一问题。本轮定向检索未发现完全对应的工作，不等于已完成查新。

### 2.5 必须准备的对照与淘汰条件

最少对照：固定无 RIS + 同等精估计资源；原稿 RIS + 原四路径估计；原 RIS + AIC/BIC/常规正则；信息设计 + 固定四路径；仅自适应估计；完整联合方法。另设理想路径信息的诊断参考，明确它不是可实现算法，也不当作严格最优上界。

当前生成器使用同一个 `p.alpha(q)` 生成各路径，而估计器允许四个独立系数。应分别检查原生成方式、符合互易/方向散射依据的不同路径系数等情况，各方法获得同等先验。**不能仅靠把四系数强绑成一个，就把匹配原生成器的收益宣称为普适改进。**

先排查初始化、压缩与局部求解，再进入设计优化。默认部署是主结果；路径强弱、目标方向接近或通信约束变化分别作为压力场景，不同时堆叠所有有利条件。改变部署获得的收益要单独归因，不能算固定部署算法收益。

以下任一结果都会削弱这条选题：常规正则/模型选择已实现全部收益；改进只追平强无 RIS；理想诊断也无有用设计空间；模型选择探测开销超过收益；改进仅存在于真值辅助或人为设置的路径缺失中。若最终只有估计器修复，应按工程改进处理，不强行写成独立新稿。

## 3. 备选主线 B：面向漏检/误锁的预算内自适应探测

候选题目：**《粗估计不确定条件下无源 RIS 多目标感知的探测协议与定位可靠性设计》**。

原流程只有粗估计锁定后才进入 RIS 精估计，并围绕一个粗结果构造固定投影基。B 的研究问题是：**还不能可靠确定目标位置时，有限 CPI 应用于排除错误假设，还是用于精化当前假设？**

候选链路：公共粗观测 → 保留多个位置/速度候选及可信度 → 根据候选选择下一组波束/RIS 和样本安排 → 更新候选 → 联合精化。所有决策只使用已经收到的观测，不能预知后续噪声或真值。

可能形成实质贡献的内容是：

- 在未知复幅度和运动条件下，构建能同时反映候选混淆与局部精度的可计算设计准则；识别局部 CRB 好而实际误锁率仍高的条件。ZZB 或多假设距离可以作为工具，不能直接作为首次应用的主张。
- 推导相位序列、Doppler 与通信可行性的相互制约，并据此设计有预算的序列/阶段策略。两组变四组不免费增加符号。若优化粗精分配，保持总 512 符号并记录各阶段变化和切换开销；所有强基线也获得相同资源上限。
- 检查压缩是否保留错误候选间的可区分信息。原 `prepare_ris_observation.m` 已包含粗位置附近的模板和距离/速度导数，因此“局部信息压缩”不是新内容。新问题只能是有限粗误差、多个候选和固定秩预算下的信息保留性质；不能单纯增加基向量数量制造收益。

这条路线潜在范围更大，工作量也更大。目前已有直接近邻：[4] 做运动多目标角度–Doppler 解耦；[5] 做多假设贝叶斯更新和波形/RIS 的假设距离设计；[6] 做 RIS 时延 ZZB。因此，仅将这些组件搬进当前模型，差异仍可能不足。必须得到原问题中不可由这些方法直接处理的新结构或性能结论。

初期可先固定原粗精分配，研究多个候选和等秩压缩；是否进一步做预算自适应，应由筛查结果决定，不预先把全部模块塞入一稿。必须与公共改进检测器、非 RIS 多候选估计、CRB 设计和已有重复相位协议比较，防止把通用检测改进误归因于 RIS。

四个全局相位只能区分经过 RIS 的阶次 0/1/2，不能单独拆开同阶次 RD/DR。运动时不能直接按静态 DFT 分离；全局旋转也会改变用户直达/反射信道的相干叠加。若不同状态重新设计波束，应在实际联合字典中处理，不能继续使用公共波束下的简化分离公式。

## 4. 本轮不优先的路线

| 路线 | 原因 |
|---|---|
| 仅改 CRB、增加相位配置或联合粗精数据 | 可作为组件，独立性不足；多个近邻已有相关设计 |
| 故障单元鲁棒设计、相位相关幅度自校准 | [7][8] 已有直接相关工作；只添加故障率和 MCRB-AO 很拥挤 |
| RIS 高分辨率双目标分离 | [2] 已有 Fisher、相干性、检测界、OMP 和关联融合，需要更具体新问题 |
| 完整三维速度向量 | 当前模型只有径向速度；单 BS/单 RIS 的两个远场方向最多提供两个独立速度投影，不能直接声称单帧恢复三维速度；20 m/600 m 几何也可能病态 |
| 有源/半无源 RIS、FAS、AI | 本轮按保留用户原无源硬件的要求排除 |

## 6. 先做什么，才值得启动长时间服务器仿真

1. 固定原稿与强无 RIS 基线，对初始化、观测压缩、四路径幅度自由度和局部求解作少量样本的机制诊断；仍保留原物理尺寸，服务器运行，本地仅冒烟。原方案结果保持原定义；新稿在同资源下另设强基线。
2. 第一轮只筛 A：完整物理参数下检查路径证据、模型选择/正则与 XYZ 风险的关系；理想诊断也不能绕过真实低 SNR 初始化。没有设计空间就停止这条路线。
3. 若存在机制，再推导边界并加入联合配置设计。建议工程门槛可先定为多个相邻 SNR 的稳定误差下降、配对区间排除零且通信可行性不退化；具体阈值在看独立正式样本前锁定。该门槛不是预测提升。
4. 正式实验提供完整脚本、在服务器使用原 16 Tx/64 Rx/256 RIS、12672 子载波、总 512 符号以及原抽样规则。算法若改变样本分配、压缩秩、阶段长度或切换预算，逐项记录并做同资源对照；本地只冒烟。
