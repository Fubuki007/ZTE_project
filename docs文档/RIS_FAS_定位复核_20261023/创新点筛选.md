# RIS + 流体天线定位：创新点筛选与可证伪方案

更新：2026-10-23。承接同目录《研究报告》，本文件只回答“创新点具体在哪里”。以下是结合代码与定向文献检索提出的**候选贡献**，不是已经证明的新定理、已完成的性能提升或“首次”结论。

## 1. 建议押一条主线

**推荐题目：可辨识性驱动的流体天线–RIS 协同宽带多目标定位。**

具体问题：在同样的天线孔径、RF 链数、发射能量、带宽、CPI 和探测开销下，FAS 能否让 RIS 辅助目标回波更容易区分，并且增加消去未知路径系数后仍然保留的三维位置信息？

这里的“可辨识”是指不同目标位置不能通过重新调整未知回波幅度而产生相同观测；它比回波功率更直接地关系到能否定位。主线采用当前 Stage-3 的 **Tx 端口可选择、固定 Rx、被动 RIS、无源运动目标、DD/RD/DR/RR 四路径**。保留现有完整宽带配置，先不叠加新的 SI/ADC 硬件模型。

可组织为三个相连的贡献：**解释何时 FAS 有独立价值 → 设计有限探测协议 → 在相同预算下验证真实定位收益**。不能把三个常见算法拼接后各列一条创新。

## 2. 主线贡献一：给出 FAS 定位增益的存在条件与失效边界

### 已知问题与需要新增的结果

当前 `stage3_model.py:geometry()` 明确给出：

\[
\tau_{RD}=\tau_{DR},\qquad \nu_{RD}=\nu_{DR}.
\]

所以更大的距离/Doppler FFT 不会从这两个维度分离同一目标的两条混合路径。当前模型仍可利用不同收发方向、频率响应和配置区分它们；**不能由“同延迟”直接推断整个模型不可辨识**。

需要针对联合字典分析：哪些目标/RIS/用户方向会让列向量或位置导数高度相关？端口变化在何种情况下只能改变可被未知系数吸收的相位/幅度？什么时候它改变了不同目标假设的可区分性？

白噪声、未知确定性复路径幅度条件下，以现有模型构建

\[
y=D(p,v;d)\alpha+n,\quad
J_{p,v}^{\mathrm{eff}}=\frac{2}{\sigma^2}\Re\{G^H(I-DD^\dagger)G\}.
\]

还要消去速度参数，不能只看原始 FIM 的位置子块。推导中区分：字典列独立、参数局部可辨识、全局唯一性，三者不等价。

### 一个已核查的反例：纯反射链路的固定阵列等价性

在只保留 RR 回波、远场单秩单位模 BS–RIS 信道、自由逐频数字波束、无通信/SI 约束且噪声/损耗不随端口变化的简化系统中，Tx 端口只通过一个馈入 RIS 的标量进入目标回波：

\[
g_{m,b}=a_m^H(s_b)w_{m,b},\qquad \|a_m(s_b)\|^2=N_t.
\]

对任意固定阵列 `s0`，取

\[
\widetilde w_{m,b}=a_m(s_0)g_{m,b}/N_t,
\]

即可复现同一个 `g`，且 `||w_tilde||²=|g|²/Nt <= ||w||²`。因此在该条件下，移动 Tx 可以产生的目标观测均值都能由固定 Tx 以不更多的功率复现，沿用相同 RIS 控制和噪声即可得到相同条件观测分布；这不只是一条功率增益结论。

**此推导仅是简化模型下的代数结果，是通信领域单秩冗余结论的定位解释，不应单独包装成重大的新定理。** 它的价值是约束主线：独立收益必须来自直达/反射方向竞争、多目标或通信约束等使等价构造失效的因素。仍须证明这些因素带来的是 FAS 的额外收益，而非固定阵列调整波束就能实现的收益。

### 与最近工作比较及放弃条件

- [Friends or Foes?，2501.15880](https://arxiv.org/abs/2501.15880) 已讨论 IRS 下 MA 通信增益消失；新增结果必须落实到四路径未知系数、位置 EFIM 与可区分性，不能复述其单秩论证。
- [FAS Fisher Information，2512.13941](https://arxiv.org/abs/2512.13941) 已做 EFIM/端口选择。重新推导本系统是必要工作，但“使用 EFIM”本身不是创新。
- [2022 年单/双散射感知，2212.07142](https://arxiv.org/abs/2212.07142) 已用固定阵列预编码/合并分离两条混合路径。主张 FAS 必需之前，必须与这种多波束基线比较。
- 若相同孔径和最优可行波束下，端口对投影后的位置信息无显著影响，这条路线就应收缩；不能改用更大孔径或真值设计制造收益。

## 3. 主线贡献二：反射参与次数、Doppler 与端口几何的联合探测

令 RIS 基础配置统一旋转 `exp(j theta_b)`，在当前 `factors()` 的相位约定下，四路径可写成

\[
y_b=d_b+e^{j\theta_b}(u_b+v_b)+e^{j2\theta_b}r_b+n_b.
\]

这里的阶次 0/1/2 指 **RIS 被经过的次数**，不是不同论文中所有“单/双散射”的命名。DD 是 0，RD/DR 是 1，RR 是 2。式中的各回波仍含真实频率、空间和 Doppler 因子。

两个相反相位只把回波分成 `DD+RR` 和 `RD+DR`；它们不能分离四路径。在同一波束/端口/基础 RIS 图样、静态或完成 Doppler 对齐的条件下，四个 2 bit 全局旋转 `0, pi/2, pi, 3pi/2` 可以正交区分阶次 0/1/2，但**仍不能区分同属阶次 1 的 RD 与 DR**。后者需要收发空间与波束配置提供额外独立响应。

潜在的新问题是：**在 2 bit RIS、目标运动、通信 QoS 和有限探测次数下，如何选择端口几何与探测配置，使消去未知系数后的最弱位置信息足够大，同时避免错误目标假设？**

有三处不能省略：

1. **运动不能按静止导频处理。** 周期四相位序列本身相当于慢时间频移。仅看慢时间因子，阶次 1 在 Doppler `nu` 的响应等于阶次 0 在 `nu+1/(4Tsym)` 的响应。当前参数对应约 27.985 kHz，若用直接单站公式解释约 149.92 m/s。它不是当前约 15 m/s 目标必然产生的错误，也不是完整空间–频率字典必然不可辨识；它要求显式使用速度先验和完整联合字典检验混叠。非匀速相位序列只是候选，不能凭一个例子宣称已解决全部模糊。
2. **通信约束可能破坏简单编码。** 全局 RIS 相位旋转会改变直达/反射通信信道的叠加，四种状态都不一定满足 QoS。若每个状态重新调整波束，前述简单 DFT 分离式一般不再成立；应使用各状态的实际已知字典联合估计，或设计同时满足四个状态的公共波束。
3. **额外回波必须可测。** 当前 `hop_amplitude=0.7` 是归一化模型，不能证明真实被动 RR 路径足够强。必须先用合理链路预算/路径衰落范围检查 RR 的价值；若 RR 很弱，强行使用四状态会浪费探测预算。

估计上，可先保留若干候选位置/路径关联，再用现有 variable projection 联合拟合位置、速度与未知复增益；只在信息足够时压缩候选。端口优先采用**上一 CPI 先验选定、本 CPI 冻结**，RIS/波束完成较快探测，避免第一版依赖帧内机械扫描。若使用帧内电子端口切换，则必须扣除切换与重新校准占用的符号。

### 最近工作与差异边界

- [2212.07142](https://arxiv.org/abs/2212.07142) 已含相反相位、预编码/合并分离混合路径，且其帧内模型忽略 Doppler、忽略更高阶散射，包括本工程 RR 类路径；不能宣称首次利用 RIS 进行路径分离。
- [FAS-ARIS，2509.12348](https://arxiv.org/abs/2509.12348) 已有 FAS、有源 RIS、三维主动 UE 定位、相反相位导频。本文候选是被动目标回波、被动 RIS、四路径与运动；仅换场景还不够，必须给出具体秩/模糊条件及有资源约束的改进。
- [RIS 路径识别，2506.04123](https://arxiv.org/abs/2506.04123) 已做动态区域/图样交替识别反射路径，研究对象为下行 UE 的信道功率检测。
- [BD-RIS 张量估计，2605.27753](https://arxiv.org/abs/2605.27753) 已研究单目标时延–Doppler–角度及可辨识条件。不能仅加张量分解作为创新；候选差异在传统对角 RIS、四路径独立未知幅度和 FAS 几何/探测预算的相互作用。
- [MA-OFDM 模糊函数，2609.34737](https://arxiv.org/abs/2609.34737) 已研究 Tx MA、固定 Rx、OFDM 三维模糊和位置/波形优化。候选需处理 RIS 路径阶次与未知增益，不能只再优化一个普通旁瓣指标。

**“四相位 DFT”“AO”“端口搜索”均只是工具。可能成立的贡献是特殊混合路径的可辨识条件，以及在实际约束下取得额外定位信息的联合配置方法。**

## 4. 主线贡献三：相同预算下，自适应配置是否值得切换

把贡献一的边界和贡献二的探测协议连起来：用上一 CPI 的估计/后验构造候选区域，决定是否重配端口、选择何种 RIS/波束探测，而非每帧强制全端口扫描。

设计指标可使用先验区域内最坏位置 PEB、最小有效信息特征值，辅以不同候选目标子空间的可区分性；信息矩阵奇异时必须报告不可辨识，不用伪逆产生虚假的低 PEB。指标选择、近似及失败处理都要记录。**这是一条系统验证贡献，只有结合前两项才有分量。**

开销/先验本身已被 [Stay or Switch，2607.26547](https://arxiv.org/abs/2607.26547) 和 [先验引导 MA 多径感知，2608.09165](https://arxiv.org/abs/2608.09165) 研究过；“考虑切换成本”或“使用先验”不能单独标新。

最少保留以下对照，每种都使用相同的完整观测和资源上限：

| 对照 | 要排除的替代解释 |
|---|---|
| 同孔径优化的固定阵列 + 多波束/RIS 探测 | 端口收益其实能由固定阵列波束复现 |
| FAS + RIS 按照射功率设计 | 收益只来自更强回波 |
| 固定阵列 + 本文信息设计；FAS + 相同信息设计 | 设计指标收益与硬件收益混淆 |
| 含真实切换/校准开销与零开销上界 | 多给时间、能量或免费导频 |
| 纯反射单秩负对照、双目标靠近、方向接近、直达减弱 | 方法只在特定有利几何成立 |
| 独立未知路径幅度与有物理依据的互易/共享幅度版本 | 把人为放大的 nuisance 空间误当成必然物理困难 |

正式指标为 XYZ RMSE、95% 误差、误锁/失败概率及通信可行率；保留所有初始化失败样本。当前 Stage-3 首半帧 RIS 关闭、DD-only 初始化，不能直接作为完全直达阻塞的算法。要研究这种阻塞，必须增加 RIS-on 初始化，并把它计入同一个 CPI，而不是只给新算法使用真值初值。

## 5. 备选方向 A：用静态参考链路校准端口切换相位

**候选题目：参考链路辅助的 FAS–RIS 相干定位与校准资源分配。**

科学问题是：扫描多个端口依赖相干参考，而每次切换的未知 RF 相位、时钟偏移可能被误认作目标几何或 Doppler。考虑端口位置已知，切换后每块存在未知公共相位/时间偏移，利用稳定的已知 BS–RIS–BS 参考回波或可分辨直耦参考，估计相对偏移，再联合定位；设计需要拿出多少样本做参考，何时应停止增加端口。

一个已核查的简化边界：窄带单路径、串行空间采样、每个样本有独立未知相位时，所有端口几何相位导数落在这些相位 nuisance 的实线性张成空间，投影后这部分角度信息消失。这不表示宽带时延信息或同时多路 Rx 的角度信息也消失。

可能贡献应是**切换相位与运动的歧义条件、可用参考的条件、校准预算与位置误差的联合权衡**，而不是又一个一般自校准 AO。最近的 [2605.23140](https://arxiv.org/abs/2605.23140) 已做 MA 阵元位置误差自校准；[JrCUP，2304.00631](https://arxiv.org/abs/2304.00631) 等已做 RIS 位姿/用户联合校准；[2404.05149](https://arxiv.org/abs/2404.05149) 已做未知 BS–IRS CSI、符号歧义和目标多假设定位。

限制：一个参考方向不能凭空校准全部三维端口位置误差；单频也不能独立区分任意 RF 相位与几何投影。先限定为已知端口坐标、低维切换相位/时间误差，并说明参考信道哪些参数已知、哪些保持稳定。当前 Stage-3 缺少这条参考回波，要增加信号和校准模型。因此它更适合作为第二阶段课题，不宜和主线全部叠加。

## 6. 备选方向 B：面向定位信息的残余 SI 整形

**候选题目：有限阶自干扰抵消下 FAS–RIS 协同定位的信息保持设计。**

科学问题：同样的残余 SI 功率，落在目标位置敏感方向与落在无关方向，会导致不同的定位损失。FAS 和 RIS 能否让数字抵消器更容易描述 SI，同时避免压低有价值的目标导数？

先指定有物理依据的有限阶宽带抵消器，使用同一端口、同一 RIS 同时构建目标与 SI 信道。分开计算“可拟合 SI”与失配/漂移残余，再以白化后的 nuisance 投影信息评价定位。若残差是随机量，可用其有依据的协方差 `R` 对 `D,G` 白化；若是未建模的确定性泄漏，必须讨论偏差/失配误差，不能直接当零均值高斯噪声套 CRB。

**必要负对照：** 静态、完整匹配、固定满秩导频和热噪声 LS 下，`Ghat=G+Zp Xp†`，残余误差为 `-Zp Xp† Xdata`。只降低真实 SI 矩阵范数不自动降低此项。无失配时应复现这个边界，不能强行让残余等于真实 SI 的固定百分比以制造收益。

[2408.00413](https://arxiv.org/abs/2408.00413)、[2505.14830](https://arxiv.org/abs/2505.14830)、[2411.04419](https://arxiv.org/abs/2411.04419) 已有 MA 全双工 ISAC/SI 设计；[2211.12293](https://arxiv.org/abs/2211.12293) 已有 RIS 在 ADC 前抑制 SI 的考虑。所以“FAS/RIS 抑制 SI”或“考虑 ADC”不够新。候选差异是**可抵消子空间、定位导数子空间和实际估计误差之间的联系**，仍需进一步专门检索和证明。

该路线与早期 MATLAB SI/SIC 工作衔接更强，但 Stage-3 当前明确没有 SI。根目录旧 worker 的 SI 不随所选目标 RIS 相位变化，也不足以直接验证这条贡献。建模工作量最大，作为备选，不与第一篇主线一起实现。

## 7. 实现落点与第一轮筛查

| 当前代码 | 下一阶段承接的研究问题 |
|---|---|
| `RIS_stage3/stage3_model.py:Config, Model.__init__, steer` | 用统一米制端口坐标重建 Tx–RIS、Tx–目标与通信响应 |
| `geometry, factors, target_dictionary` | 四路径及每次已知配置；核查相位阶次和速度假设 |
| `RIS_stage3/streaming.py:Observation.statistics, fit, refine` | 复用精确分块 Gram 和 variable projection，计算消去幅度/速度后的信息 |
| `coarse_from_records` 与两阶段协议 | 设计 RIS-on 探测启动；禁止用 DD-only 初始化冒充阻塞定位 |
| `RIS_stage3_ai` 的 context/physics/protocol | 主线成立后才接入新目标/新端口；旧照射训练权重不代表定位信息最优 |

`streaming.py` 每个数据分块重新构建 `Model(cfg, indices)`，所以后续端口配置必须经过 Config、观测记录、仿真与统计器全链路传播；只修改某个 Model 实例不会完成接入。

第一轮先检查信息矩阵、强固定阵列基线、RR 可测性和探测开销，再决定是否进入全量算法实现。正式性能比较必须提供完整脚本、到服务器使用原 16 Tx / 64 Rx / 64 RIS / 12,672 子载波 / 256 符号运行，保存随机种子、断点和真实进度。若收益不成立，应保留负结果并改变假设或选题；不能用增加神经网络规模掩盖。
