# 三个问题的当前判断与验证方案

日期：2026-10-23。依据当前代码、已有正式全量结果、同目录文献/代数核查，以及本轮新增的理想平板传播量级检查。本轮不是 FAS 性能实验。

## 1. 判断先行

| 问题 | 当前答案 | 已有依据与缺口 |
|---|---|---|
| 定位困难是否存在？ | **结构上可能存在；默认场景没有显示出严重失效。** | 未知增益会消耗定位信息；但当前 1,100 个正式样本没有出现已定义的大误差事件，照射优化本身已有明显收益 |
| FAS 是否具有额外价值？ | **需要新仿真，现在不能回答“有”。** | 特定纯 RR 单秩条件下已知无独立价值；多方向与通信约束下存在合理机制，但未实现端口模型，也未与强固定阵列比较 |
| 收益能否经受实际约束？ | **现有模型不足以支持该结论；传播预算存在明显风险。** | RIS 幅度是归一化参数，尚无器件、RCS、反射损耗及端口开销的校准；理想平板参考表明真实反射路径可能弱得多 |

因此，当前阶段适合做**增益存在性与物理可行性验证**。论文不能先写成“已解决严重误锁”或“FAS 必然改善 RIS 定位”。

## 2. 第一问：现有数据究竟说明什么

本轮直接核对 `server-results/stage3/results_full_mc100/` 的 manifest、进度与 CSV，来源身份为 `03a610c5c0eada886318f53262e052eeacf11492926d7ffdbfcc2bd22e487b5c`，11 个 SNR 点各 100 次，完整 1,100 个样本；不是使用本地 smoke 推断。

- 优化 RIS/发射波束的角度 RMSE，相对 DD 联合精估计降低 **44.9%–51.9%**。
- −30 dB 时，角度 RMSE 为 **0.037988° → 0.020317°**。
- 四种方法所有 SNR 点的 `outlier_rate` 均为 0。这里角度事件定义是单次试验有任一目标的 theta/phi 绝对误差超过 5°；距离/速度的事件定义是超过一个原生 FFT 栅格。不能把零次观测事件解释为真实失效概率严格为零。
- 默认目标距离差为 9.8 m，且当前配置已具备很强的宽带/阵列/时间积累；标为 −30 dB 的平均样本信号/噪声比不等于积累后仍缺少信息。
- 现有优化方案的通信 SINR 有较大余量：历史完整核查记录最低约 18.20，门限为 2。不能默认原场景的定位正被紧通信 QoS 卡住。

**结论：默认场景尚不支持“严重混叠/误锁是当前主要瓶颈”。**

理论上，回波功率与消去未知幅度后的位置信息不等价，RD/DR 也确有同延迟/同 Doppler 结构。但这些结构事实尚未证明现有场景的性能损失来自该机制。应把研究假设限定为：在合理的方向竞争、目标接近、直达减弱或紧通信约束下，照射设计可能没有有效改善位置最弱方向。

不能把全领域都说成“只看 SNR”：已有 FAS/RIS 定位、位置 CRB、模糊/MSE 和路径分离工作。候选新贡献必须针对本系统形成具体机制与比较结果。

## 3. 第二问：必须怎样仿真，才能归因给 FAS

### 3.1 理论筛查与信息检查

先保留已推导的负对照：RR-only、远场单位模 rank-one BS–RIS、自由逐频数字波束、无通信/SI 约束和端口相关损耗时，固定阵列可复现移动 Tx 的馈入响应。因此不能期待这里出现 FAS 独立信息增益。

然后使用完整四路径字典，消去未知复幅度、速度后评价三维位置 EFIM/PEB。端口、频率、波束、RIS 图样全部一致进入字典。若采用真值或真实路径幅度辅助搜索，必须标为**理想诊断参考**，固定阵列与 FAS 获得同样信息；有限候选搜索不是全局最优界，更不是可实现算法结果。

这个阶段检查的是模型中是否存在值得追求的设计空间。若只是某个局部优化器没有找到收益，不能据此证明所有 FAS 都无收益。

### 3.2 最少四组方法

| 编号 | 天线 | 设计目标 | 作用 |
|---|---|---|---|
| A | 固定阵列 | 现有照射功率 | 保留当前基线 |
| B | 固定阵列 | 位置信息 | 识别换设计目标本身的收益 |
| C | FAS | 照射功率 | 识别端口对原目标的收益 |
| D | FAS | 与 B 相同的位置信息 | **D 对 B 才是主要硬件增益比较** |

固定阵列不能只放原始 URA：需增加在相同允许孔径/间距内、由独立设计场景选定的优化固定几何，在线同样优化波束与 RIS。FAS 的在线端口选择使用粗估计/跟踪先验；测试真值不进入可实现设计器。不能给 FAS 任意几何自适应，却把对照限制为一个未优化波束。

固定阵列的固定几何应在独立场景上确定；若给它按每个测试真值重新选阵形，应标为 oracle 可重构参考，不能同时称为实际固定硬件。所有非凸求解器记录预算、可行性、重启和收敛，不宣称获得全局最优。

### 3.3 正式实验必须保持的公平性

- 16 Tx RF 链、64 Rx、64 单元 RIS、12,672 子载波、256 符号、2 bit 与双精度；正式运行在服务器。
- 固定/FAS 使用相同允许孔径、最小间距、总功率/能量、噪声、频带和总时长。候选端口必须来自同一物理场，不能各抽独立衰落。
- 每个场景冻结一个共同的噪声参考，不随方法或所选端口重新定义 SNR；噪声、散射和种子配对。
- 首次 RIS-on 探测、校准和端口切换的开销纳入总预算；所有方法采用同样可用的先验/公共初始化。
- 维持原始场景作为常规组，再分别改变目标接近程度、目标/RIS/用户方向关系、直达强弱或 QoS；不要一次同时改变所有因素，也不只报告最有利案例。
- 报告 XYZ RMSE、95% 误差、失败/误锁概率及通信可行率，以独立几何/MC 为合理单位给出配对置信区间，保留失败样本。

还需要机制归因：若 D 的收益完全由回波能量增加解释，能够主张资源利用改善，但不能声称已证实额外的位置可区分性。可另做单位回波能量的信息分析；若人为匹配接收 SNR，应明确它只是分析对照，不能替代相同发射预算的主实验。

**判定规则：** 信息改善和实际估计改善同时出现，且 D 稳定优于 B，才支持这条主张。信息改善但 RMSE 不改善，说明初始化/估计可能是瓶颈；只有 A 对 D 的提升，不能把收益单独归因于 FAS；只有 oracle 或更大孔径才改善，也不足以支持当前故事。

## 4. 第三问：目前最需要正视的是物理链路预算

按 64 个半波长单元的面元面积计算，取

\[
A=64(\lambda/2)^2\approx0.001837\ \mathrm{m}^2
\]

即约 18.37 cm²。BS–RIS 距离约 17.55 m，两目标的 RIS–目标距离约 192.26 m / 200.53 m。

使用一个明确限定的参考模型：远场、理想相干平板、正面入射/出射的有利参考、反射效率为 1；比较相同量级 BS 定向增益和目标散射下的自由空间传播因子。平板散射截面近似 `sigma_RIS ≈ 4 pi A² / lambda²`，单条传播腿的反射/直达场幅比为

\[
\eta\approx \frac{A R}{\lambda d_{BR}d_{RT}}.
\]

两目标分别得到约 **0.01019 / 0.01025**，对应传播功率比约 **−39.8 dB**。如果出射和回程都经 RIS，在同样假设下，RR/DD 场幅比量级约为 `eta² ≈ 1e−4`。

**这个估算不是标定信道、不是所有被动 RIS 的严格上界，也不是定位性能结果。** 它没有标定单元方向图、极化、互耦、波束方向增益、目标双站 RCS 和遮挡，不能把该值直接作为实测事实。特别是直达受阻或两方向照射增益不同，相对路径比会改变。

但是，它足以揭示一个模型风险：当前归一化 `hop_amplitude=0.7` / 双程 0.49 **不能直接当作这套硬件几何下的实际路径幅比**。0.7 也不等于器件反射效率为 70%；它还替代了几何、孔径和级联传播。

因此第三问目前的答案是：**不能保证收益在实际被动链路下保留，优先检查有效反射孔径和路径功率，再研究端口优化。** 若主要反射路径在合理模型下已过弱，FAS 不会自动补足传播损耗；若只在归一化模型中成立，论文主张就必须限定在该模型。

在物理路径仍可用的前提下，再评估端口切换/校准损耗、RIS 相位与幅度误差、先验偏差和处理延迟。先采用本 CPI 端口冻结可降低帧内扫描要求，但跨 CPI 重配的时间/能量依然要计入长期资源预算。

## 5. 故事应该如何更新

当前不能写：“原系统因四路径混叠严重失效，FAS 解决了问题。” 现有结果没有支持这个前提。

可检验的叙事是：“针对通信与探测资源受限的 RIS 辅助宽带定位，分析端口重构的独立收益条件；在物理可用的反射链路和相同资源下，验证信息导向的端口/波束/RIS 设计能否改善实际定位。”

这个故事的核心结果仍然取决于第二问的新仿真。第一问须先定位实际瓶颈，第三问须保证选用的物理模型足以支撑想研究的机制。
