# RIS + 流体天线定位：论文、现有代码与近期文献复核

日期：2026-10-23。代码基线：`63127db2e6f41cf94b69594c6b37ed632e7ed684`。本文是阅读与选题分析，未实现 FAS 定位算法，未运行新的定位性能实验。附带计算仅为几何和线性代数核查。

## 1. 判断与推荐

**能加入，但不能把“RIS + FAS + 定位”作为创新本身。最适合当前代码的第一步，是在 Stage-3 四路径模型上增加基站发射端离散端口 FAS，研究被动 RIS 辅助的宽带三维被动目标定位。接收阵列先保持固定。**

这里的“定位”指车辆等不主动发送定位导频的雷达目标。它与“手机主动发导频，基站估计手机位置”是两类观测模型。若实际课题要定位主动 UE，应转向下文的 FAS-ARIS 上行框架；两者不能混称为同一实验。

推荐研究问题：

> 在未知路径复系数、有限观测时间和粗定位不确定性下，哪些 FAS 端口与 RIS 配置能增加真正可用的位置信息，并降低错误锁峰？什么几何与信道条件下，FAS 的额外收益会消失？

可用工作题目：**有限观测预算下 RIS 辅助宽带 ISAC 的流体天线端口设计与三维可靠定位**。这是待验证的研究方向，不是已证实的论文创新。

相比 2026-10-09 的旧调研，本次建议有两个实质变化：

1. 接入基础优先选择已经形成的 `RIS_stage3`，不把旧 MATLAB 单次反射模型当成当前唯一实现。最新 Stage-3 本身没有 SI，因此不必第一步就同时增加 FAS、宽带 SI 和新 SIC。
2. 新核查到直接涉及 FAS-RIS 三维定位的 FAS-ARIS 论文，以及 2026 年 9–10 月有关 MA-OFDM、实际 MSE 和定位阵形的论文。仅“改成 CRB”“加入假峰”“换一种 AO 算法”都已有很近的工作。

## 2. 用户提供的论文讲了什么

论文：Jiang 等，*Intelligent Reflecting Surface Aided Dual-Function Radar and Communication System*，IEEE Systems Journal，DOI：[10.1109/JSYST.2021.3057400](https://doi.org/10.1109/JSYST.2021.3057400)。所提供文件共 12 页；已提取全部页面，并检查系统模型与仿真页面的渲染。

论文第 3 页式 (1) 写成：

\[
y_R=(G^H V A V^H G+B)wx+n_R.
\]

其中 `B` 是 BS–目标–BS 直达回波，`G^H V A V^H G` 是 BS–IRS–目标–IRS–BS 的 IRS 辅助往返回波。这里按论文原符号转写；实现时必须统一互易信道、转置/共轭与 RIS 系数约定，不能直接把它和另一套路径公式混接。

第 4 页式 (11) 的设计是：联合优化发射波束 `w` 与连续 RIS 相位 `V`，**最大化雷达接收 SNR**，满足用户 SNR 门限、发射功率和单位模约束。求解采用交替优化：波束子问题用 SDR 或一阶近似与二分，RIS 子问题用 MM、SDR 和随机化恢复。

论文采用固定阵列、理想 CSI 和归一化噪声/路径参数。仿真主要比较雷达 SNR 随迭代次数、RIS 单元数、通信门限和功率的变化。它没有给出本项目这种 OFDM 三维位置估计完整链路，没有显式的矩阵 Tx–Rx SI 与实际导频 SIC，也没有研究 FAS。

因此，该论文可以提供“RIS 改善照射与回波”的基础，但不能直接作为“加入 FAS 后三维定位更准”的证据。论文将雷达/通信一体化后的互干扰问题简化处理，也不能据此认为真实全双工射频泄漏会自动消失。

### 3.2 Stage-3 值得保留的部分

- `Config`：28 GHz，12,672 子载波，120 kHz 间隔，16 Tx、64 Rx、64 RIS 单元，256 符号，2 bit RIS。
- `Model.steer()`：直接接收米制坐标，逐子载波生成响应，天然适合扩展发射端位置。
- `geometry()`：由同一个目标位置生成 BS/RIS 两个观察方向，四条路径各自的时延和 Doppler。
- `target_dictionary()` / `factors()`：构造与估计器一致的四路径字典。两条混合路径有相同总时延/Doppler，但收发方向不同，不能仅凭时延把它们当成两个可独立分辨的锚点。
- `Observation.statistics()`：用分块 Gram 累积保留全量频点、Rx 阵元和符号；可以用于位置导数与 Fisher 信息计算，不必物化巨大的观测雅可比。
- `Observation.refine()`：变量投影消去未知路径幅度。已有的投影/Schur 补结构与 EFIM 思路接近，但当前它是估计器，不是已实现的 PEB 设计器。
- `context_from_model()`：设计者使用粗估计，不传目标真值。FAS 扩展应继续保持此边界。
- 匹配、配对噪声、逐样本恢复和全量服务器运行框架可复用；新增 XYZ 指标也应沿用同一目标关联。

### 3.3 接入前必须面对的具体限制

**第一，当前设计优化的是照射，尚未优化位置。** `Model.illumination()` 和 AI 的 `physics_numpy.illumination()` 使用直达/反射照射功率之和。它没有直接评价接收空间响应、未知系数消去后剩余的位置导数，也不描述全局假峰。功率高不必然带来最小位置误差。

**第二，当前 BS–RIS 是归一化远场 rank-one LoS。** RIS 位于 `(12,-10,8) m`，距 BS 约 17.55 m；它与旧 MATLAB 中距 BS 仅 `1.5λ` 的 RIS 是不同场景。Stage-3 的 `hop_amplitude=0.7`、双程 0.49 是明确指定的归一化耦合，尚不是按物理面积、RCS、损耗校准的被动 RIS 链路预算。

**第三，保留任意 Rx 移动不是简单改坐标。** 旧 `joint_estimator_fast.m` 与新 `coarse_from_records()` 都包含规则阵列的相邻相位差初始化；非规则 Rx 会破坏这一前提。先做 Tx-only FAS 可以保留 Rx 几何，但仍要更新发射响应、用户信道、波束和估计字典。

**第四，仅修改某个 `model.tx` 实例会失效。** `streaming.py` 在信号生成和统计时反复按 `Model(cfg, indices)` 重建模型。选定端口必须进入配置/观测记录，并传播至每个分块模型。否则设计端看到 FAS，模拟器和估计器仍会使用固定 URA。

**第五，当前粗估计依赖 DD。** 第一阶段关闭 RIS，靠直达回波初始化。因此现有流程不能直接宣称支持完全遮挡 DD 的 NLoS 初始定位；这种情况必须另加 RIS 开启的粗探测协议，并计入相同符号预算。

**第六，一条通信流不等于全带宽发射矩阵必为秩一。** Stage-3 允许每个子载波使用不同的 `w_m`；跨所有频率/符号堆叠后，波形的空间秩可能大于一。不能因为 `K_stream=1` 就直接套用 R7 的全波形 rank-one 模糊函数结论。

### 4.1 与 FAS-ARIS 最关键的区别

R1 的系统是 **主动 UE → FAS 基站**，采用 **有源 RIS** 与端口扫描合成孔径；本文建议的系统是 **BS → 被动目标 → BS**，采用 **被动 RIS**、16 条 Tx 链和 64 路同时接收的原工程资源。R1 可借鉴链路分离、AoA/几何与 CRB，但它的有源增益、放大噪声、扫描时长和导频开销不能直接迁移或忽略。

它也说明：如果最终题目只有“FAS 与 RIS 融合三维定位”，重叠会很大。需要在观测架构与可验证的新机制上进一步缩小问题。

R1 的一个可借鉴操作是重复两段导频、让 RIS 相位整体相反，再通过加减分离直接与反射信号。但在本工程四路径模型中，`phi→-phi` 使 RD/DR 两条单次反射变号，DD 与 RR 两条偶数次反射不变。因此在波束/端口相同、信道相干且完成 Doppler 对齐的条件下，加减只能分离“DD+RR”和“RD+DR”，**不能直接分离四条路径**。R1 还依赖几何直达分量足够强以识别主峰，不能把其方法解释为任意完全遮挡、多径环境下都可直接定位。

### 4.2 阅读公式时需要保持独立核查

R2 使用 `log det(J)` 做信息设计，但 **最大化行列式不一般等价于最小化 `tr(J^{-1})`**：前者是 D-optimality，后者对应位置平方误差界的 A-optimality。三维例子：`diag(100,1,1)` 的行列式为 100，大于 `diag(4,4,4)` 的 64，但其 PEB 为 1.418，大于后者的 0.866。

因此可借其研究框架，不应照搬这种等价表述。对于未知公共复增益/相位，还应从样本模型重新做 nuisance 消去，核查复共轭、单位、端口中心化和相干参考；直接套一个端口坐标平方和可能高估位置可辨识信息。

## 5. FAS 放在哪里更合适

| 接入方式 | 能改变什么 | 代价与判断 |
|---|---|---|
| 基站 Tx FAS、固定 Rx | 目标与 RIS 的照射方向相关性、通信–感知波束冲突、多路径发射响应 | **优先。** 与现有坐标导向矢量和固定 Rx 粗估计最兼容；额外收益需先验证 |
| 基站 Rx FAS、固定 Tx | 接收孔径、角度信息和空间模糊，必要时 SI 零陷 | 定位作用更直接，但要修改相位差初始化；串行端口扫描不能当作 64 路同时观测 |
| UE FAS | UE 主动通信/定位的接收或发射空间采样 | 改变课题对象，不能直接改善当前无源雷达目标的回波模型 |
| RIS 单元本身移动 | 表面几何与反射孔径 | 属于可移动单元 RIS/FRIS，变量、硬件及校准明显增加，不作为第一版 |

FAS 不要求真的模拟液体流动。第一版可以建模为每条 Tx RF 链在少数已知端口中选择一个位置；连续机械移动通常用 MA 表述。需要说明真实采用的位置/形状/方向图重构方式。候选端口数不是 RF 链数，候选端口也不能各自重抽独立随机信道。

## 6. 建议采用的模型与设计指标

### 6.1 统一四路径观测

令 `s` 为选定的 Tx 端口，`phi` 为全带宽共用的 RIS 控制向量，`w_m` 为子载波波束。建议沿用：

\[
y_{m,l}=\sum_{q=1}^{Q}\sum_{a\in\{DD,RD,DR,RR\}}
\alpha_{q,a}\,b_{q,a}(f_m;s,\phi)\,
g_{q,a}^{H}(f_m;s,\phi)w_m
e^{-j2\pi m\Delta f\tau_{q,a}}e^{j2\pi\nu_{q,a}t_l}+n_{m,l}.
\]

四条路径由同一目标坐标决定；改变端口后，Tx→目标、Tx→RIS、Tx→UE 的响应都重算。所有频率使用同一套米制天线/RIS 坐标，不能随波长改变硬件位置。当前径向速度闭合假设可以先保留，但必须记录。

各路径复系数暂设未知；是否跨观测子块共享，要有目标相干性与端口相位校准依据。不能把每个新配置引入的未知相位都当成已知测距信息，也不能把 RR 路径的时延直接除以二当作 BS–目标距离。

若后续恢复 SI，再增加共同几何决定的

\[
H_{SI}(f_m;s,\phi)=H_{direct}(f_m;s)+G_{Rx,RIS}(f_m)\operatorname{diag}(\phi)G_{RIS,Tx}(f_m;s)+H_{scatter}(f_m;s).
\]

目标、通信与 SI 必须使用同一 RIS 配置。根目录旧 worker 的 SI 矩阵不会随 RIS 相位变化；不能只打开该开关就说完成了统一模型。

### 6.2 消去未知系数，再评价三维位置

把所有观测堆叠为 `y=D(z;d)alpha+n`，其中 `d=(s,phi,{w_m})`，`z` 包含所有目标位置与速度。在白噪声、未知确定性复幅度的条件模型下，令

\[
G=\frac{\partial(D\alpha)}{\partial z},\qquad
\Pi_D^{\perp}=I-DD^{\dagger},\qquad
J_z^{eff}=\frac{2}{\sigma^2}\Re\{G^H\Pi_D^{\perp}G\}.
\]

再对速度等实参数作 Schur 补，得到位置 EFIM `J_p`。多目标使用联合信息矩阵，保留目标间耦合。`J_p` 可辨识且正定时，三维 `PEB=sqrt(tr(J_p^{-1}))`；不可辨识方向应标为无界，不能简单用伪逆把零信息方向变成零误差。

这个投影有实际含义：若端口变化只引起一个可被未知复系数吸收的缩放/相位，增加的信号功率未必等于增加的可用定位信息。当前 `Observation.statistics()` 的 Gram/交叉项可用于构建该信息矩阵。

设计需要的目标位置、幅度、速度应来自粗估计/跟踪先验及其不确定性，真值仅用于 oracle 上界。最初可以最小化先验网格内最差或期望的 `tr(J_p^{-1})`，并约束通信 QoS、功率、可用端口、间距和 2 bit RIS。

低 SNR 再评价候选位置/多目标假设的字典子空间相似性或轮廓似然间隔，并用实际误锁率验证。因为 R6–R8 已覆盖假峰/MSE，仅引入这个项也不构成充分创新。

### 6.3 为什么 FAS 不一定有效：必须保留负对照

在简化的远场 rank-one BS–RIS LoS、纯反射链路、幅度恒定且无其他波束约束的条件下，发射导向矢量每个元素模长为 1。采用单位功率匹配波束：

\[
w=a(s)/\sqrt{N_t},\qquad |a^H(s)w|^2=N_t,
\]

与端口位置无关。本次 12 个坐标配置的代数核查最大误差为 `3.55e-15`。这不是完整定位实验，只说明该极限模型中不能期望“移动 Tx 就增加反射照射功率”。

真正值得研究的是直达与反射方向竞争、有限相位、通信约束、多目标混合、位置先验与多路径可辨识性如何打破这个边界。近场 BS–RIS 或更丰富散射可能带来额外自由度，但若改模型，必须同时对固定阵列基线使用同一模型，不能只给 FAS 引入有利多径。

若转向 SI，完整匹配、静态、热噪声 LS 的基线满足 `G_hat=G+Z_p X_p^dagger`，故给定同一导频与数据时残差为 `-Z_p X_p^dagger X_data`。仅减小真实 `||G||` 不自动减小该残差；有限阶宽带失配、漂移等机制必须有物理依据。此路线可以作为后续课题，先不用与第一版 FAS 四路径定位同时实现。

## 8. 协议、资源与实验应怎样公平

### 8.1 沿用的正式配置与已知假设

| 项目 | 当前基线/要求 |
|---|---|
| 物理规模 | 28 GHz，16 Tx、64 Rx，64 单元 RIS，12,672 子载波，256 符号，2 bit |
| 带宽、CPI | 1.52064 GHz；约 2.28693 ms |
| 几何 | 初始采用 Stage-3 的 RIS 与双目标几何；多场景测试另行冻结配置 |
| 数值与实现 | complex128/float64、全频点与分块精确累积；新增近似逐项记录 |
| 模型边界 | 归一化 RIS 幅度；目标对小阵列远场；CPI 内位置冻结、径向速度闭合；频域理想观测，不是实测射频链路 |
| 正式计算 | 服务器全量运行，保存参数、种子、源码哈希、逐样本断点、日志、真实进度 |

当前 Tx/Rx 阵列对角孔径约 2.27 cm / 5.30 cm，对应 Fraunhofer 距离约 0.096 m / 0.525 m；200 m 目标不是这些阵列的近场目标。若增加大孔径或改变目标距离，应明确这是新场景。RIS 同为 8×8 半波长阵列，其对角孔径与 Rx 相同。

原单站距离 FFT 栅格约 0.09864 m；第一目标在 200.6 m 处，1° 方向误差对应约 3.50 m 的横向尺度。因此“距离分辨率约 0.1 m”不能用来宣称“三维定位 0.1 m”。

### 8.2 端口更新时序

建议先采用慢端口配置：通过上一 CPI/跟踪先验选择端口，整个当前 CPI 固定；当前 CPI 粗估计后更新 RIS/W。首帧从固定配置开始。它容易与现有两阶段协议兼容，但必须真实生成先验误差，不能把当帧未知真值作为先验。

若要求端口也根据当帧 128 符号粗估计立即更新，就需要电子切换/重新校准，并把损失的符号从后 128 符号中扣除。若切换耗时为 `t_sw`，需至少明确 `ceil(t_sw/T_sym)` 个损失符号以及新增训练。未获得硬件时延时应扫描参数，不能默认开销为零。

Rx 单 RF 链依次扫端口形成的虚拟阵列尤其需要相干与运动补偿；它不能以相同 CPI、相同独立噪声样本数免费替代 64 路同时接收。

### 8.3 最少需要的性能对照

1. 固定阵列、无 RIS；固定阵列 + 优化 RIS。
2. FAS、无 RIS；FAS + 随机/分别优化的 RIS。
3. FAS + RIS 按照射功率设计；FAS + RIS 按位置 EFIM 设计。
4. 同资源的 EFIM 设计 + 全局模糊/候选可区分性处理。
5. 真值先验仅作 oracle 上界；保留纯反射远场 rank-one 的低收益/无照射增益负对照。

基线必须具有相同 RF 链数、允许孔径、功率/能量、RIS 面积、频带、时间和训练预算。如果让 FAS 使用更大的可移动区域，还要比较同区域内合理优化的固定阵列；不能只和更小孔径的原 4×4 阵列比较。端口密集时还需说明间距、互耦/切换损耗的建模边界。

实际位置从 `p=R[sin(theta)cos(phi), sin(theta)sin(phi), cos(theta)]` 计算，其中 theta 沿用从 z 轴计的定义。位置 RMSE 应先对匹配后的欧氏平方误差跨 MC/目标求均值再开根；另报 CDF、尾部和失败率，不能丢掉锁错峰或初始化失败样本。

先验证原场景，再加入目标接近、直达减弱、先验偏差、多径强弱和不同端口/相位预算。若收益只来自扩大孔径、使用真值或多给导频，就不能作为 FAS 协同定位的贡献。AI 求解器后接入，并报告含校正/回退的总延迟。

## 9. 哪些贡献值得继续，哪些不够

| 设想 | 当前判断 |
|---|---|
| 原论文固定天线换成可移动天线，再做 AO | 重叠明显，R3 与 DFRC 系列已覆盖 |
| RIS + FAS，SNR 换成 CRB/PEB | R1、R2、R4 已非常接近 |
| MA/RIS 加神经网络或 GPU | R10 等已有，且加速照射优化不等于改善定位 |
| CRB 之外考虑假峰/实际 MSE | R6–R8 已覆盖该原则 |
| 四路径中消去未知系数后的信息边界，解释什么时候 FAS 无额外价值、什么时候有效 | **值得先分析**，需要针对本模型形成可验证的新结果，不能仅复述 R5 |
| 相同宽带/相位/训练/切换预算下，端口与 RIS 如何改善多目标路径可区分性与真实位置尾误差 | **可作为主问题**，仍需与 R1、R6–R9 深入逐项比较 |
| 有限阶 SIC 下任务相关残差与定位信息联合设计 | 可作为延续原 SI 工作的另一条路线，建模和验证代价更高；不能只把 SI 功率减小作为机制证明 |

建议先做“收益存在性”筛查，再投入大规模训练：固定硬件和观测预算，对比不同配置的投影位置信息、纯反射负对照以及少量真实估计冒烟。若在合理先验下信息几乎不变，就先调整问题/场景，不应直接增加 MC 或训练规模来期待出现收益。
