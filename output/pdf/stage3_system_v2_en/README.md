# Separate English system figures

- A_system_model_en: RIS-assisted mmWave MIMO-OFDM ISAC system.
- B_target_geometry_en: target angle definitions; theta is measured from the z-axis.
- C_four_sensing_paths_en: DD, RD, DR, and RR sensing paths and total delays.

Each figure is supplied as PNG, editable SVG, and vector PDF.
Run draw_system_figures_en.py with Python and ReportLab to regenerate PDF and SVG files. Fonts: Arial and Arial Bold from Windows.

The figures retain the model in Section II, pages 2-5, equations (1)-(27), of the supplied ZTE_period___stage_3___submit.pdf. Positions and array element counts are schematic. The main scene shows a representative user k and target q. The two RIS symbols in the RR sequence represent the same physical RIS. No simulations are run.
