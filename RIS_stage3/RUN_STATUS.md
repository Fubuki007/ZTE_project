四条曲线在角度、距离、速度图中含义一致：

- **灰色方块 DD FFT**：RIS 关闭，固定通信 ZF 波束，利用完整 CPI 的距离–多普勒 FFT、峰值插值和空间相位差估计参数，作为参考。高 SNR 时距离/速度平台反映此参考算法的插值等近似偏差，不能视为无 RIS 系统的精度极限。
- **蓝色三角 DD joint refinement**：RIS 关闭，使用同一 ZF 波束，由 FFT 初始化，对距离、径向速度和两个角度作连续联合精估计，未知路径系数用最小二乘拟合。与灰线比较主要反映精估计算法收益。
- **黄色菱形 Random RIS + joint refinement**：前半 CPI 关闭 RIS 粗估计，后半使用随机 2 bit 相位，发射波束仍为 ZF，按几何相关的 DD/RD/DR/RR 四路径联合精估计。距离/速度上与蓝线几乎重合，说明本场景中仅随机开启 RIS 的收益很小。
- **红色圆点 Stage-3 optimized RIS**：由粗估计联合优化全子载波共用的 2 bit RIS 相位与逐子载波发射预编码，在通信 SINR 与总功率约束下增强感知，再做四路径联合精估计。结果支持整套联合方案的收益，无法单独归因于 RIS 相位优化。

其中 DD 是 BS→目标→BS，RD 是 BS→RIS→目标→BS，DR 是 BS→目标→RIS→BS，RR 是 BS→RIS→目标→RIS→BS。三项指标的提升幅度不同：该场景中角度收益约 45%–52%，距离与速度约 14%–20%。绝对数值适用于已声明的已知波形、固定双目标、热噪声和归一化级联链路模型，不能直接视为实测设备精度。
