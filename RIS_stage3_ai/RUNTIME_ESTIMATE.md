使用服务器 jzm 的一张 RTX 3090、4 个 BLAS/PyTorch CPU 线程、独立 Python 3.11 / Torch 2.8.0+cu126 环境。物理尺寸完整：12672 子载波、Tx 4×4、Rx 8×8、RIS 8×8/2 bit、128+128 符号 CPI、双精度。GPU 峰值分配内存约 1.80 GiB，不等于显卡总占用或多进程可用容量保证。

当前单进程安排下，准备数据加训练大致是 **11–12 小时量级**，完整六方法测试另计。数据已经生成以后，反复训练无需重做这一项。

连续、量化训练和验证各测 3 次，外推使用中位数。把每组最小/最大时间分别代入，总训练+验证为 2.69–3.95 小时；这不是统计置信区间，最大值含首轮初始化开销。数据生成只测训练和验证各一个场景，均为协议首个 SNR（−30 dB），不同几何/SNR/资源负载可能改变耗时。

训练步计时包含物理上下文、很小的网络/Adam 新建和实际计算；不包含保存大量历史检查点、日志和资源竞争。验证使用初始网络和同一校正预算，不能保证正式训练后的每个场景都同样快。没有根据这组测时自动增加并发、减少样本或改变物理尺寸。
