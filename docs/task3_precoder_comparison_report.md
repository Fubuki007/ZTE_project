## 1. 实验设置

### 1.1 三种预编码方案（来自 bf.m）

| 方案          | 原理                                         | 来源       |
| ------------- | -------------------------------------------- | ---------- |
| **ZF**        | 传统迫零，不考虑自干扰                       | bf.m 的 W0 |
| **Nullspace** | 零空间投影，将发射信号投射到 SI 信道的零空间 | bf.m 的 W1 |
| **Lagrange**  | 拉格朗日法，通信质量与 SI 抑制的最优折中     | bf.m 的 W2 |

> 注：Nullspace 和 Lagrange 在实际实现中加入了**自适应 Tikhonov 正则化**，防止 SI 信道矩阵病态时数值崩溃。

scale 为 SI 信道矩阵功率的缩放倍数。scale=0 表示无自干扰基线。

## 3. 通信约束偏差分析

`comm_err` 反映预编码矩阵偏离理想通信波束的程度（`‖W - W_ZF‖_F / ‖W_ZF‖_F`）：

| 信道        |   ZF   | Nullspace | Lagrange |
| ----------- | :----: | :-------: | :------: |
| E1_LoS      | 9.0000 |  0.6664   |  0.0000  |
| E2_mixed    | 9.0000 |  0.0472   |  0.0472  |
| E3_Rayleigh | 9.0000 |  0.2720   |  0.2718  |

> 注：ZF 的 `comm_err = 9.0` 是哨兵值（ZF 自身就是通信最优基准，不参与 SI 抑制，也未归一化偏差计算）。

### 关键规律：

1. **E1_LoS（κ=10000）**：Lagrange 的 comm_err = 0（完美通信约束），Nullspace 的 comm_err = 0.67 → Nullspace 波束被严重扭曲。
2. **E2_mixed（κ=1）**：Lagrange 的 comm_err = Nullspace 的 comm_err = 0.047 → **两者行为趋同**，都无法保持正确的波束方向。
3. **E3_Rayleigh（κ≈0）**：两者 comm_err ≈ 0.27，**完全相同**，但角度估计仍然准确 → 瑞利信道下即使通信偏差存在，估计器仍能恢复目标角度。

## 5. 结论

1. **E1_LoS 下只有 Lagrange 可用**。ZF 对任何 SI 都敏感（scale=1 即崩），Nullspace 因通信约束偏差（comm_err=0.67）在无 SI 时角度误差就达 7°。Lagrange 在所有 SI 强度下角度误差 < 0.07°。
2. **E2_mixed 下三种方案均不理想**。Lagrange 在此信道下通信约束偏差与 Nullspace 相同（comm_err=0.047），角度误差 ~7°。这是本实验的重要发现——E2 的 SI 信噪比条件（κ=1）使 Lagrange 的正则化失去了对通信约束的保护能力。
3. **E3_Rayleigh 下 Nullspace 和 Lagrange 均可工作**。ZF 在 scale=10 时崩溃。瑞利信道下即使通信偏差为 0.27，估计器仍能锁定正确角度。
4. **E2_mixed 下 Lagrange 失效是值得深入分析的现象**。建议：
   - 检查 Lagrange 的正则化参数在 κ=1 时的选择是否合理
   - 考虑动态调整 Lagrange 乘子 μ，在不同 κ 下自适应平衡通信约束与 SI 抑制
   - 或在 E2 场景下测试其他折中方案（如增加通信约束权重）

## 6. 建议

| 信道        | 推荐方案     | 说明                                       |
| ----------- | ------------ | ------------------------------------------ |
| E1_LoS      | **Lagrange** | 唯一全范围正常工作的方案                   |
| E2_mixed    | ⚠️ 待优化    | Lagrange 失效，需调正则化参数或改进算法    |
| E3_Rayleigh | **Lagrange** | 与 Nullspace 均可用，Lagrange 角度误差略优 |

- **E2_mixed 的 Lagrange 失效**需进一步排查：在 `design_precoder.m` 中增加 comm_err 的监控输出，验证 Lagrange 乘子 µ 是否在 κ=1 时收敛到不合理值。
- 考虑修改 Lagrange 目标函数中通信约束的权重，或对 µ 设置上下界，防止通信约束在特定 SI 条件下被过度放宽。
