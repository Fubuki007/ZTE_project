# 调制之后，数据在 NN-DPD 里经历了什么

> 调制（QAM + OFDM）结束后，你得到一段时域复数波形。下面只讲这段波形进入 DPD 之后发生的事。

---

## 输入：一段复数波形

调制器出来的东西长这样：

```
时刻 1:   0.52 - 0.31j
时刻 2:   0.81 + 0.12j
时刻 3:  -0.23 + 0.67j
...
时刻 131520:  0.11 - 0.45j
```

131520 个复数，每个复数就是一个时刻的波形取值。

这个东西直接送进 PA 会被非线性压扁。所以要先过 DPD，提前"反向扭曲"一下。

---

## 第一步：把复数展开成 30 个实数

神经网络只能处理实数，不能直接吃复数。所以第一步是把每个时刻的信息**展开**。

但问题来了：PA 的失真不仅取决于"此刻"的信号，还取决于"刚才"的信号（记忆效应）。所以展开的时候不能只看当前一个点，要看**最近 5 个点**。

### 1.1 滑动窗口取 5 个点

```
要预测时刻 n 应该怎么修正，NN 看到的是：

  x[n-4]    x[n-3]    x[n-2]    x[n-1]    x[n]
    ↑         ↑         ↑         ↑         ↑
  4个时刻前  3个时刻前  2个时刻前  1个时刻前   现在
```

### 1.2 每个点拆成 6 个实数

一个复数 x[n] = I[n] + j·Q[n] 被拆成：

```
I[n]      ← 实部
Q[n]      ← 虚部
|x[n]|    ← 幅度（信号有多大）
|x[n]|²   ← 幅度的平方
|x[n]|³   ← 幅度的立方
|x[n]|⁴   ← 幅度的四次方
```

为什么要加 |x|、|x|² 这些？因为 PA 的非线性本质上就是"信号越大，压得越狠"。|x|²、|x|⁴ 这些量恰好能量化"信号有多大"以及"非线性的强度"。把这个信息显式喂给网络，比让网络自己从 I/Q 里猜要高效得多。

### 1.3 拼起来：5 × 6 = 30

```
x[n-4] → [I, Q, |x|, |x|², |x|³, |x|⁴]  ─┐
x[n-3] → [I, Q, |x|, |x|², |x|³, |x|⁴]   │
x[n-2] → [I, Q, |x|, |x|², |x|³, |x|⁴]   ├─ 拼成 30 个数
x[n-1] → [I, Q, |x|, |x|², |x|³, |x|⁴]   │
x[n]   → [I, Q, |x|, |x|², |x|³, |x|⁴]  ─┘
```

**131520 个复数 → 131520 组 × 30 个实数**。每组对应一个时刻，包含了"现在和最近过去"的全部信息。

---

## 第二步：神经网络做判断

30 个数进入一个 4 层全连接网络：

```
30 个数（输入）
   │
   ▼  第1层：30 个数 → 30 个数（加权求和 + LeakyReLU）
   │
   ▼  第2层：30 个数 → 24 个数（进一步提炼）
   │
   ▼  第3层：24 个数 → 19 个数
   │
   ▼  第4层：19 个数 → 2 个数
   │
   ▼
输出：[I_out, Q_out]  两个实数
```

每一层做的事都一样：**把上一层的每个数乘以一个权重，全部加起来，过一个非线性函数，传给下一层**。逐层提炼之后，最后浓缩成两个数。

这两个数的含义：**在当前这个时刻，输出信号应该取什么样的 I 和 Q，才能抵消 PA 即将产生的失真**。

网络共约 2000 个权重。这些权重不是人设定的，是训练时从数据里学出来的（见下一节）。

---

## 第三步：两个实数拼回一个复数

网络输出的是归一化后的 I_out、Q_out，除以缩放因子恢复实际幅度：

```matlab
dpdOut[n] = (I_out + j·Q_out) / 112.96
```

**131520 组 × 2 个实数 → 131520 个复数**。这就是预失真后的信号，形状和输入一样（一串复数），但每个点的值被网络"微调"过了。

---

## 第四步：预失真信号送进 PA

```matlab
paOutput = pa(dpdOut);
```

PA 看到的是已经被反向扭曲的信号。PA 自身的非线性把信号再扭曲一次——两次扭曲方向相反，互相抵消，最终输出接近原始信号的线性放大版本。

```
原始信号 x  →  [NN-DPD]  →  x̂（反向扭曲） →  [PA]  →  ≈ x（线性放大）
```

---

## 总结：三句话

1. **复数→30维实数**：滑动窗口取 5 个历史点，每个点拆成 I、Q、|x|、|x|²、|x|³、|x|⁴，拼成 30 个数。

2. **30→2**：4 层全连接网络把 30 个特征压缩成 I_out、Q_out 两个数——这是网络对该时刻"怎么反向扭曲"的判断。

3. **2→复数**：I_out + j·Q_out 除以缩放因子，还原成预失真信号，送进 PA。

---

## 这个网络是怎么训练的？（ILA）

训练的关键问题是：我们没有"正确的预失真信号"作为标签。我们只有干净信号和 PA 的输出。

ILA 的做法：反过来训。

```
训练时：
  干净信号 → PA → 失真信号 → NN → 预测
                                │
                          和干净信号比，算误差

  NN 学会：把失真信号变回干净信号
           （等价于学会 PA 的逆操作）
```

训好之后，部署时正着用：

```
部署时：
  干净信号 → NN → 预失真信号 → PA → 线性化输出
```

**训反用正**。这是 ILA 的核心。

## 补充：记忆多项式 DPD（传统方法对比）

作为基线，示例还实现了一个不使用神经网络的 DPD——记忆多项式（MP-DPD）：

```
y[n] = Σ Σ a_{k,m} · x[n-m] · |x[n-m]|^{k-1}
        k  m
```

就是把历史信号按固定公式加权求和，系数 a_{k,m} 用最小二乘一次性解出来。

和 NN-DPD 的区别：
- MP-DPD：**人规定了公式长什么样**，只调系数
- NN-DPD：**人不规定公式**，让网络从数据里自己学映射关系

NN-DPD 的优势在于可以捕获 MP 公式之外的非线性模式。
